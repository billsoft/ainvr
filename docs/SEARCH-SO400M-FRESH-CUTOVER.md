# 智能搜索模型切换记录：当前已回切 SigLIP2

当前状态：2026-10-30 已执行回切 SigLIP2-256 / full-int8 / 768 维，目标包为 `siglip2-base-full-int8`。本次新配置版本及最终运行验收结果以主线程随后发布的部署报告为准；下文的 so400m v18 及其运行数字仅为此前上线的历史记录，不代表当前状态。

本次回切只更换搜索模型并清空 so400m 搜索派生数据，重新积累 SigLIP2 搜索样本与索引；保留现有代码逻辑以及切换前全部 `sampling` 和 `limits` 参数，不恢复旧 SigLIP2 搜索数据。录像、识别历史、告警及证据不在清理范围内。

## 当前运维入口

`deploy-package/search_fresh_model_cutover.mjs` 是明确的破坏性运维入口。每次必须显式指定源包和目标包，仅接受 SigLIP2 与 so400m 之间的两个方向，拒绝同包、未知包或省略方向。`--check` 只预检，`--apply` 才切换；设备已切换后，原方向的重复执行会因源包不匹配而拒绝。

回切 SigLIP2 的预检与正式执行命令分别为：

```sh
node deploy-package/search_fresh_model_cutover.mjs --check --from siglip-so400m-i18n-full-int8 --to siglip2-base-full-int8
node deploy-package/search_fresh_model_cutover.mjs --apply --from siglip-so400m-i18n-full-int8 --to siglip2-base-full-int8
```

此为本次使用的运维命令记录，不是再次执行的要求。将来若另获授权切换到 so400m，仍须显式使用 `--from siglip2-base-full-int8 --to siglip-so400m-i18n-full-int8`。反向回切完整保留采样与限制参数；正向切换保留此前的有界采样策略。

脚本保留独立持有的部署 flock、搜索集合白名单、源模型单空间检查、SSD 索引归属检查、停止全部相关 writer 后清理，以及配置 CAS 并发检查。磁盘 manifest 按源包维数验证（so400m 为 1152、SigLIP2 为 768）；新运行就绪状态按目标包及匹配的文本/视觉模型版本验证，禁止混用向量空间。

代码回滚包只存 SSD，使用共享保留机制，每服务最多 3 份。代码回滚不恢复已获授权删除的旧搜索数据；不能通过回滚二进制混用两个向量空间。失败时保持搜索停止，核对部署记录后恢复。

反向策略及就绪检查已通过 `node --test test/search/search-fresh-model-policy.test.mjs` 的 12 项测试；脚本通过 `node --check`。这些软件检查不替代本次部署报告中的实际运行验收。

## 历史：此前 so400m 上线（已被本次回切取代）

历史状态：2026-10-30 此前部署包为 `siglip-so400m-i18n-full-int8`，1152 维，正式搜索配置 v18。以下均描述该次历史切换，不修改旧安装迁移的种子匹配条件。

### 历史链路契约

- 文本塔、视觉塔、分词器、归一化、向量维数必须属于同一经过哈希校验的完整词表模型包。不能只切文本塔或只改包名。
- 视觉适配器按包验证输入/输出契约和实测资源预留；so400m 视觉输出为 `1×1×1152`。采样组装、归一化使用包声明的维数，拒绝跨包输入规格。
- 图像仍由 GLES/JPU 处理，模型只使用 BPU。模型及分词器在系统盘 `ai-service/models/search/`；搜索样本、图片和覆盖数据保留统一历史库管理，派生索引在已选择的 SSD 目录。
- 共存登记锁、登记文件属主、内存预算及加载后余量试分配继续生效，不修改 boot/ION 分区、不绕过准入。
- 单在途采样任务保持有界。该次上线设置同一目标重复采样至少间隔 4 秒，活动场景 20 秒、静态场景 60 秒、场景变化最短 5 秒。新目标首样不受重复间隔限制；不修改目标检测 FPS。这些数字不替代本次回切前实际保存的参数。
- 相似度不是置信度。页面保留 0–0.20、默认 0.07 的筛选操作；更换模型后该阈值仍需按现场调节，不保证两个模型的同一分数等价。

### 历史数据切换

该次历史切换经用户明确授权清空旧 768 维搜索数据、从 so400m 重新积累。停止 AI 采样、搜索和控制台后端写入后，清理了 11,238 条旧搜索样本、4,310 条覆盖记录、2 个搜索控制记录和 2 个磁盘索引分片；搜索任务、结果会话及旧模型 pin 同步清理。

该次历史部署未清理录像、识别历史、告警及其证据，未更改通道、热区、计数或触发器配置。用户并行开发的统计分析页面没有包含在该次部署中。
