# 布防统一编辑界面（2026-10-23）

普通平面热区直接在布防工作区编辑。点击热区显示角点、边中点和右侧名称/关联列表，无需进入形状编辑页。

- 拖动内部整体移动；矩形角点改变宽高，边中点改变单边；矩形不插点。多边形保留插点。
- 每次完成拖动只形成一个撤销步骤；指针取消或失去捕获恢复原状，无效形状不进入草稿。
- 名称在右侧修改；空名、重名会阻止切换及保存，关闭仍可确认放弃。
- 新建矩形松手后自动选中；多边形逐点绘制后点“完成绘制”。原有热区始终显示。
- 概览显示名称、已关联触发器和已关联计数器；点击添加或已关联卡片后，侧栏切换为独立关联视图，隐藏概览及其他添加入口。完成关联或返回关联会校验并暂存有效设置，再回到概览；没有选择时直接返回，未完成的无效设置提供放弃确认。关联卡片用蓝色/青色区分类型，明确显示已关联、未启用及需重新设置状态。
- 设置计数线或触发方向时，画面交互用于选边；返回概览后恢复形状手柄，避免选边同时拖坏热区。
- 顶部删除仅删除所选热区及其关联，需要确认，支持撤销；最终一次“保存布防”生效。
- 取消/关闭检查整个草稿（包括待输入名称及绘制中的形状），未保存修改确认后丢弃。
- 保留全景环绕区域的原有 360° 视角调整工具；普通平面编辑没有“编辑形状与名称”入口。

计数线仍引用稳定边 ID；移动顶点保持 ID，拆分边后相关计数关联需要重新确认；方向关联继续沿用原有变更确认保护。不同热区的计数绑定继续独立。
