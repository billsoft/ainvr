## 唯一部署入口

本板有效 Compose：`/etc/ainvr/infra/compose.yaml`。固定配置与秘密位于系统盘，增长数据位于 SSD。

```bash
docker compose -f /etc/ainvr/infra/compose.yaml ps
systemctl status ainvr-infra
journalctl -u ainvr-infra -n 80 --no-pager
```

仓库 `/mnt/ainvr-ssd/ainvr/deploy/infra/.env` 指定该 COMPOSE_FILE；`secrets` 是到 `/etc/ainvr/infra/secrets` 的软链接，已加入本仓库本地 Git 排除规则。不要显式以仓库默认 compose.yaml 执行 up，否则会重新使用 S100P 默认内存额度和不同 PG 路径。

执行停止/启动使用 `systemctl stop/start ainvr-infra`。其 ExecStop 只停止容器，保留数据。Docker 本身还有 unless-stopped 策略；未来接入授权执行器后需按产品授权策略协调 SRS，当前仅完成基础设施。

本板将 **PG 整库放 SSD**，不另建 eMMC PG 或 tablespace，以避免 WAL、任务、审计和版本历史在 eMMC 增长。PG 中的参数也随库放 SSD；系统盘保留的是固定启动配置、密钥及模型。并未迁移操作系统自身全部日志/缓存，不应声称 eMMC 完全零写入。

应用库/角色：PG `ainvr_config` / `ainvr_config`；Mongo `ainvr_snapshots` / `ainvr_ai`。数据库密码文件位于 `/etc/ainvr/infra/secrets`，勿打印。Mongo `ainvr_alarm` 专用用户、后端业务 PG migrations、配置主密钥和业务服务身份要在后续 AINVR 安装阶段创建，当前未伪造完成。

## SSD 缺失保护

Docker/containerd 的 `/etc/systemd/system/<unit>.d/10-ainvr-ssd.conf` 和 `ainvr-infra.service` 包含：

- `RequiresMountsFor=/mnt/ainvr-ssd`。
- 对实际 SSD mount unit 的 `BindsTo` 和 `After`。
- `ExecStartPre=/usr/bin/mountpoint -q /mnt/ainvr-ssd`。

fstab 使用 nofail 允许无 SSD 时进入系统维护，但这些依赖服务不得因此回退到系统盘同名目录。已在私有 mount namespace 隐藏 SSD，验证同一 mountpoint 检查拒绝启动；真实挂载未卸载。fstab 经 findmnt --verify 通过。**本次未重启整块板，也未做物理拔盘测试。**

## S100 初始内存预算

| 组件 | 容器上限 | 关键设置 |
|---|---|---|
| PostgreSQL | 384 MiB | shared_buffers=64MB、max_connections=40、work_mem=2MB、maintenance_work_mem=32MB |
| MongoDB | 768 MiB | WiredTiger cache=0.25GB、zstd |
| SRS | 768 MiB | HLS tmpfs=256MiB，非预分配，包含在容器资源预算中 |

容器日志各 10 MB × 3，SRS 非阻塞日志缓冲 4 MB。上述额度为新板初始小负载设置，不代表高码率多通道容量已验收。HLS 需要按总码率、窗口及峰值重算；不得直接套用 .189 的 2 GiB HLS 盘，否则会挤占仅约 4.3 GiB 的 Linux 内存。

实测数据库和流媒体运行后整机 available 约 2.6 GiB，属于观测时刻值；未加载 AI/LLM/search。2B 模型的 ION 准入与检测、视频并发压力另行验证，不能以此保证 7 GB ION 必然足够。

## 验证与边界

实测结果在 verification.json、mount-gate.json、storage.json、hls.json。包含数据库应用账号读写、重启后的持久性、Mongo 无认证读取拒绝、回环监听、RTMP/SRT→HTTP-FLV 和 HLS 低分辨率合成流。

合成流为 640×320 H.264，CPU 编码仅用于隔离基础设施验收，不是生产 AI 的 CPU 回退。未验证真实相机高分辨率吞吐、浏览器 WebRTC、AINVR 页面、长时间并发或全板冷启动。
