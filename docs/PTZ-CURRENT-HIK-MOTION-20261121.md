# 当前海康球机：控制优先与布防恢复

## 交付范围

只针对 190 当前海康球机及其已确认的 ONVIF / GB/T 28181 双接入。设备别名来自已有 `AINVR_PTZ_MOTOR_GROUPS`，不会按 IP 或相似名称自动合并其他摄像头。

普通警戒区仍按当前视角绘制。转动后暂停关联告警与计数，重新核对后恢复。正式预置位布防保留原来的回位核验流程。本次不宣称任意角度的热区投影，也不扩大巡航、模型或多品牌兼容范围。

## 操作变化

- 已安装逐帧保护的通道，云台在 PostgreSQL 持久化转动保护后即可响应，规则同步在后台完成；不再等待告警服务确认整份规则，也不在获取控制权时重置 AI 跟踪编号。
- 紧急停止先发真实停止命令，确认停止后返回。告警服务同步失败不会阻塞已安装保护的停止结果；设备未确认停止仍明确报错。
- 同一球机的两种协议共用一个持久化保护状态和版本。任一入口转动都会保护另一入口关联的 AI 输出；恢复前核对全部当前有效的普通布防。
- 普通区域编辑器勾选当前画面核对后，可以直接“保存并恢复布防”，也保留“仅保存”。保存成功、恢复失败会分别显示，并允许只重试恢复，避免重复保存。
- 固定机位继续原有布防方式，不调用 PTZ 帧准入接口。

## 一致性与故障边界

迁移 036 引入 `ptz_motion_scopes` 和 `ptz_motion_guard_installations`。规则发布携带输入来源、处理器、guard epoch 与原始执行规则摘要。告警服务确认完整来源集（含没有当前规则的别名）安装后，后端才启用快速控制路径。尚未安装的范围使用原来的同步保护路径，不能因为当前 PG 中没有活跃规则就假定 Mongo 中旧规则已经消失。存在缺少来源身份的启用旧规则时，不开启快速路径，直到无此旧规则的新快照被确认。

每个受保护的新输入在计算前请求一次短事务准入。该事务与转动保护共用配置版本锁；事务内不访问 Mongo 或其他网络服务。PG 不可用时不能跳过保护直接转动，也不继续解释新帧。已获授权并持久化的旧帧结果可幂等完成，它表示转动前的历史事实，不可授权下一帧。

新视角恢复后，执行版本与连续性检查断开旧轨迹历史，避免跨转动区间计数。人工核对记录仍绑定实际输入、处理器、冻结画面和几何版本；只有保存记录不等于已经恢复。

首次双协议守卫归并在事务内保守暂停，清除不兼容的旧位姿基线，保留各入口恢复时间的最大值，并撤销旧范围的安装 ACK。时间边界不能倒退。延迟到达的旧 ACK 不得重新开启快速控制。重复启动不再次归并、加版本或清空配置。租约中途新增、删除或改绑输入/AI 输出会使旧租约停止，需重新申请；实时帧率等状态变化不算配置变化。

## 发布约束

后端与告警服务必须联合升级，禁止只发布支持快速控制的后端而保留旧告警消费者。联合发布前必须处理完旧消费者的未完成结果，不能删除历史数据或给旧结果补发新授权。新告警程序应从不可变发布目录运行，避免开发仓改动直接影响下次服务重启。

默认保留用户区域、计数器、触发器、模型配置及摄像头预置点 32。升级可暂停相关布防，但不能静默认定新的画面已核对。
