# 实时监看 360° 观看

每个实时监看播放器底部工具栏右侧、全屏按钮旁提供 360° 开关；开启后在旁边显示重置视角按钮，默认平面显示。该功能适用于已拼接的 2:1 ERP 全景源；宽高比本身不证明投影类型，普通画面不要开启。当前通道协议没有统一的源投影字段，因此使用显式手动开关，不根据 AI 截图投影设置自动开启。

鼠标拖动改变方向，滚轮缩放；触屏单指拖动、双指缩放。重置视角恢复初始方向。切换仅改变观看端显示，同一个 video 元素继续解码 WebRTC、FLV 或 HLS，不新增连接、不重新编码。关闭或离开播放器时释放 Three.js 资源，按需加载渲染库。

全景模式支持 SEI 识别框、类别、置信度和关键点，沿用底部识别框开关。复用 AiDetectionOverlay 的逐帧/近似取帧、300ms 过期和空结果清框逻辑，只替换绘制函数。ERP 框四边按最多 2 度间隔采样，使用与视频球体一致的 UV 方向和摄像机矩阵投影；近裁剪面先裁剪再投影，背面标签隐藏，接缝保持连续经度。Canvas 用 2px 线宽绘制，限制每帧最多 256 个框、每边 180 段。录像回放本轮不接入。

使用 WebGLRenderer（需要 WebGL2）；渲染异常或纹理尺寸超过设备上限时回到平面。浏览器仍需支持原视频编码和分辨率，降低画布尺寸不能降低完整视频的解码负担。iOS/Android/macOS 必须通过实机验收，不能以桌面浏览器通过代替。保留现有播放器全屏能力，本轮不新增移动端全屏模拟。

视频帧回调驱动渲染，无该接口时以 25Hz 检查更新；拖拽和窗口变化也触发绘制。后台或不可见时跳过渲染，画布像素密度最高 1.5。视频分辨率变化时重建纹理，保持原播放连接。

全屏按钮进入后切换为“退出全屏”，普通/全景模式可在全屏内直接切换。按 Esc 或浏览器退出也同步按钮状态。全屏工具栏常显且置于绘制层上方；不支持页面全屏的浏览器明确提示使用通道放大，不调用仅显示视频的原生全屏。

## 录像回放复用

录像回放与实时监看共用 `PanoramaView`、`PlayerViewControls/usePlayerView` 和全景识别框投影。开启 360° 时只改变显示方式，复用当前 video 的解码帧，不新增连接、不改变时间或倍速。控制条右侧提供重置视角、360° 开关和全屏/退出全屏；两种模式可在全屏内直接互换。浏览器退出全屏也会同步按钮状态。

回放识别框仍按录像 PTS 读取并选择 SEI，显示时使用当前全景相机投影。换段会释放旧视频纹理并绑定新视频；暂停时可拖动视角，寻址后刷新画面。WebGL 不可用时回到普通回放。抓拍和下载继续保存原始画面/录像，不改变文件内容。360° 适用于 2:1 ERP 内容，普通摄像头不需要开启。
