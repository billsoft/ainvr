# AINVR decoded-frame detection snapshots

The bounded ainvr_pipeline_probe now accepts optional arguments after classes.json: a new snapshot directory and projection mode (none or erp_equirect). It keeps each decoded frame alive through preprocessing, real model inference, postprocessing and all target snapshots, then advances. Every accepted detection gets an indexed image and report entry; failure aborts the probe rather than silently dropping the crop. Snapshot generation is synchronous and separately timed. Files are renamed from temporary paths after writes complete. This test sink is not fsync-durable archive storage.

Run python3 test/ai_port/verify_pipeline_snapshots.py on the board. It uses the preinstalled /app/res/assets/bus.jpg sample, converts it to a two-frame H264 MP4 and runs the uploaded yolo26m.onnx with the native CPU ONNX provider. Both ordinary and ERP mode runs yield five real detections per frame, ten images per mode. All 20 images decode without errors and have report-matching dimensions; source PTS are exactly 0 and 100000000 ns. Ordinary image snapshots were visually checked for the detected bus and pedestrian. ERP mode uses the same ordinary image only to exercise the switch, not to claim panorama accuracy.

Evidence: test/results/pipeline-snapshots-20261011-180328-627081/summary.json. The ordinary run uses JPU for an even 124x320 crop and CPU JPEG for odd-width/height crops. Five-crop totals were about 118 ms first frame / 9.5 ms second frame; these two samples are not a sustained throughput benchmark. All 20 CTest groups passed; the previous no-snapshot SCRFD/YOLO pipeline checks also passed (test/results/native-pipeline-20261011-180352-854470).

The board sample SHA256 is c02019c4979c191eb739ddd944445ef408dad5679acab6fd520ef9d434bfbc63. It matches the independently downloaded Ultralytics example at https://github.com/ultralytics/assets/releases/download/v0.0.0/bus.jpg (test-only source retained in test/runtime/pipeline-snapshot-assets). No reference submodule files changed.

This probe demonstrates the connected path and does not claim a deployed AI channel service.
