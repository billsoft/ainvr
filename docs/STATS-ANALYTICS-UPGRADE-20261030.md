## 功能与交互

- 总览沿用原型的紧凑工具栏、下划线页签、白色卡片；客流、热区、规律按任务分区。计数器、位置和时间范围共同定义统计范围。
- 方向名称使用配置值；单向计数不制造离开数据。覆盖不足显示已记录量和未知值，不伪造同比、高峰或完整客流。
- 刷新同步计数器配置、告警及区域观测，包括固定历史时间范围。地图位置与区域观测选择联动。
- 平面图编辑仍只规划摆放位置，不修改检测区域；浏览时等比居中适配。没有底图时按已有规划内容适配，不被空白画布挤小。
- 真实画面热度以独立 Konva 图层嵌入对应规划位置，保留原始画面宽高比；零值透明，区域框不填色。它是画面网格嵌图，不是经过相机标定的地面投影。
- 通行计数示意与真实画面热度明确区分。前者由区域计数生成相对强弱示意，不能当作区域内部轨迹。总览仍使用计数示意，热区页可选择真实画面热度。
- 热度支持时间段、画面版本、透明度、冷区阈值、网格读数、CSV 和录像跳转。视觉阈值不改变统计值和导出值。父子面板共享同一次查询结果，不额外采集。
- 录像参照复用现有录像接口，只接受同通道同尺寸；解码尺寸再次校验。历史镜头姿态未校验，页面明确标识；无匹配录像时保留坐标网格。
- 停留查询按模型标签版本隔离，提供累计时长门槛、观测样本和样本导出。门槛不是互斥时长分桶；片段数不是跨摄像头去重人数。
- 数据落后于查询结束时间时提示具体更新时间，并链接通道状态。

## 数据和算法修复

1. 基础告警、计数及覆盖写入先于可选停留/热度写入。可选批量写入设置驱动和应用层时限，失败记录缺口并允许检查点推进，不再阻塞基础告警链路。缺口不以零值冒充正常观测。
2. 停留事实携带 label_map_version；规则连续性包含版本、输入源和尺寸。相同 class_id 在不同模型版本不能混算，历史未知版本单独处理。
3. 查询边界裁剪观测时长及样本结束时间，门槛只根据查询范围内可见片段计算，避免未来观测泄漏到历史报表。
4. 长停留超过一小时或片段上限后抑制重复停留事实，但保留最小连续状态继续累计热度。预测 coast 不计入有效观测，真实断流仍切断连续性。
5. MongoDB 使用确定性事实 ID、检查点和现有保留策略保证重放幂等；没有引入第二套消息队列。超时降级可能留下保守缺口标记，即使迟到写入最终成功，也不夸大覆盖。
6. 热度单位是观测目标·秒，是采样观测下限；覆盖率是采集有效时段覆盖，不是识别准确率。不同区域版本、来源、画面尺寸和标签版本保留分组边界。
