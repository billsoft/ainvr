# 告警与行为统计：交互先行规格

2026-10-19，依据用户最新要求。用于驱动实际前端和后端开发，不是已完成的界面验收。

## 用户任务与入口

用户任务顺序：看实时画面 → 标记哪里需要关注 → 指定关注谁和什么行为 → 检查识别是否符合预期 → 看统计或处理告警。

实时预览工具栏新增「警戒区」显示开关与「编辑警戒区」，保留独立「检测框」「轨迹」开关。查看不改变配置。编辑是明确模式，不让普通点击画面意外改区域。

告警中心三个本期页面：告警列表、监控规则、行为统计。警戒区从规则页和实时预览都可打开同一编辑器。VLM 复核与通知不显示为可用功能，仅保留后台扩展契约。

## 流程一：从实时预览建立区域

1. 用户点击编辑，切换为当前原始输入帧的静止参考画面；标明采集时间，正在录像和直播不暂停。
2. 编辑栏提供矩形、多边形、撤销、重做、完成绘制。矩形支持拖动，也支持先点一个角再点对角；多边形逐点点击，必须有明确完成按钮，不能依赖双击。
3. 画面保留宽高比，绘制范围只覆盖真实图像，不包含黑边。全屏、横竖屏、窗口缩放都不能改变原始坐标。
4. 选中顶点后可以拖动或用方向键微调；触屏命中区至少 44px。删除选中顶点提供按钮，不依赖键盘。绘图区域编辑时限制触摸滚动，画面外仍可滚动。
5. 输入名称，显示区域颜色和接近缓冲带；自相交、少于三个点、零面积即时提示，不允许保存。
6. 「保存区域」仅保存区域，不暗中创建或启用告警。成功后提供「添加监控规则」和「返回实时预览」。
7. 保存失败保留草稿并可重试；版本冲突显示服务器已修改，允许重新载入或复制为新区域，不直接覆盖。
8. 取消或切换来源时，未保存修改需选择继续编辑或放弃。打开编辑器本身不写数据库。

区域变更影响已启用规则：显示受影响规则数，保存时生成新区域版本并同步规则版本，明确提示该目标的行为过程将重新判断，禁止用旧状态跨几何版本推断穿越。

## 流程二：创建监控规则

三步操作，桌面采用左侧参考画面、右侧表单；iPad 竖屏堆叠，底部固定上一步/下一步/保存操作，不遮挡输入框。

### 第一步：对象与范围

来源通道只选接入管理已有通道和对应 AI 处理器，不创建 SRS 流。选择已有警戒区，或打开上述编辑器。仅「出现」允许选择全画面。

标签以名称和稳定 ID 显示复选列表，支持搜索、全选和清空。全选只选择当前已知标签，不自动吸纳未来标签；至少选一项才能继续。选择变化立即显示选中数量和摘要。模型/标签版本改变且 ID 无法匹配时阻止启用并定位失效项。

### 第二步：行为与触发

四组复选项：出现、接近、接触/侵入、穿越。其中接触和侵入可分别选。选中行为才展开其相关参数，避免一次展示所有高级字段。

- 出现：连续观测时长。
- 接近：缓冲范围，画面同步显示；单位为画面比例，不伪称米。
- 接触/侵入：解释框相交与参考点外→内的区别；参考点可选中心/底边中心。
- 穿越：显示进入侧和离开侧两组方向。默认不限，高级选项提供角度扇区；12 点为画面上方，不等于地理北。
- 去重：默认同一目标本次活动只生成一条告警，阶段追加到详情；离开时间/距离满足条件才允许再次触发。
- 预测、遮挡和不完整轨迹的限制放在就近说明中，不能让“估计补全”看起来等于真实观测。

画面可演示配置几何，但明确是规则预览，不是模型实际检测结果。

### 第三步：用途与启用

规则名称、级别、时段；用途提供「只记录行为用于统计」「记录行为并生成告警」。默认保存草稿，用户明确点击「保存并启用」才开始监控。

提交前摘要用用户语言列出来源、区域、标签、行为、方向、时段及是否生成告警。保存请求中版本冲突不能自动重试覆盖。保存成功不等于服务已经应用；显示等待应用、已生效或失败，保留重试/查看日志入口。

## 流程三：告警与统计

告警列表仍一行一条，显示时间、来源、区域、目标、最新阶段、处理状态；展开详情看同次活动的行为时间线和证据。确认使用独立弹窗，支持批量，不改变行为事实。

行为统计：时间范围、来源、区域、标签、行为、方向筛选；「发生次数」「跟踪目标数」分开命名。点击数量进入对应行为事件列表，再进入证据详情。示例或无数据不能冒充实时统计。

接近→侵入→穿越属于不同指标，不把三个计数相加当人数。跟踪换 ID 可能影响目标数，说明其非真实独立人数。

没有事件且覆盖完整才显示零；覆盖未知、断流、积压时显示记录数量及不完整提示。时区明确，查询边界 [开始,结束)，跨日不重复计数。告警确认/屏蔽/合并不改变统计。

## 现有界面迁移边界

`pages/AiChannels/AnalyticsRuleEditor.tsx` 是旧隐藏功能，含「留空表示全部」和越线等旧协议，不直接启用或改造成 AI 服务内的告警规则。新编辑器属于告警功能，通过 Web 后端保存 PG 区域和规则，告警服务消费版本化配置。

## 必须通过的交互验收

U01 鼠标与触屏均能完成绘制、改顶点、撤销、保存、取消。
U02 1024×768 和 768×1024 下关键操作不被遮挡；触控目标≥44px，常规表单文字16px。
U03 无区域、未选标签、失效标签、无视频帧、非法多边形都有明确状态，不能误启用。
U04 保存失败/冲突保留草稿；切换页面或来源有未保存提醒。
U05 仅键盘可完成标签选择、规则设置、确认弹窗；焦点恢复正确，Escape 取消，文本框 Enter 不提交。
U06 修改区域显示受影响规则；画面缩放、黑边和横竖屏切换不改变区域位置。
U07 只统计模式不产生告警，但行为查询可查到；确认告警不改变统计值。
U08 重复输入结果不重复计数；完整穿越与仅越线/初始在区域内有不同结果。
U09 未完成的 VLM/通知不提供可点击启用入口。
U10 系统配置只报告实际应用状态；仪表盘离线/缺测不显示伪零。

先将以上流程落实为可操作页面并走通，再据页面所需动作补充接口和服务接线。后台已有模块继续保留，但测试通过不能替代上述用户操作验收。
