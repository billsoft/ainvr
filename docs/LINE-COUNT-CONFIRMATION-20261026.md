## 行为契约

原单线仅要求在容差带外的两侧真实观测及目的侧稳定 120ms。当前 5.4px 容差下 +/-6px 稳定抖动仍可能形成往返。本次增加距离确认：两侧均需至少两次真实观测达到容差的 2 倍，目的侧仍需连续稳定至少 120ms。当前现场确认距离为 10.8px（原图），沿所选边的实际法线测量，旋转和非正方形图像保持正确。

起点侧已证明的距离在缓慢接近边界时保留，避免慢速正常跨线被丢弃；目的侧退入确认带会重置确认时长。依旧检查有限线段，不能越过延长线冒充通行。无冷却锁，不合并不同身份，真实返程可以再次计数。

这是保守的抖动抑制规则，不是用真实标注集标定出的最优阈值。小幅真实跨线后立即折返可能被过滤；大于确认带的检测抖动或持续错误目标仍可能误计。只有检测/轨迹而没有人工录像真值，不能证明人数绝对正确。

## 兼容

新证据 confirmation.policy 为 line-observed-sides-v2，并记录 clearance 与 clearance_unit。旧历史证据保留。首次读取旧单线状态时只清除该目标未完成的旧线候选，重新积累真实观测；不重置数据库历史计数、不改绑定和客户配置。升级瞬间进行中的通行可能不能补齐证据，不跨旧策略强行确认。
