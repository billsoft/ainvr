本轮核查 11 个配置页面的 UI、保存接口、配置适配器及运行时消费路径。未提交或推送。保留现有通道、历史数据、密码、网卡、授权、数据库地址。

## 本轮修复

- 参数库缺少 backend 文档时，首次部分保存继承当前运行配置，而不是用缺少必填项的局部文档覆盖。AI 连接子项按字段合并，访问密码摘要不进入配置文档；遗留 AI 出站密钥转存加密的规范密钥位置，不覆盖已存在的规范密钥。
- 首次进入配置页回显运行配置，避免把硬编码的 SRS 地址误当成设备现值。未修改 AI 密钥时不提交空值覆盖它。
- 应用结果以所有相关服务的版本确认和当前状态为准，不能凭过去成功的任务或某一个服务的时间戳声称全部生效。
- 网络管理独立于参数库文档加载；参数库故障时仍能进入网络恢复页面。
- 告警、拉流、远程协助、手动校时的草稿纳入分类切换提醒；拉流配置读取失败明确显示不可用。
- 补充数据库、AI 连接、告警保存的生效范围说明。

## 各页生效方式

| 页面 | 核查结果与生效方式 |
|---|---|
| 基础配置 | 监看和轮询参数保存后刷新共享设置缓存；密码走专用加密凭据流程，不能经普通配置导入绕过。 |
| 数据库配置 | 参数库连接只读，属于部署配置，变更后需重启 Web 后端并准备新库；AI 历史库变更先校验，需重启 AI 时由应用任务处理并等待确认。 |
| 流媒体配置 | SRS API 地址更新客户端；外部地址供后续连接使用。WebRTC 候选地址重载后新播放连接生效，旧窗口需重新打开。拉流上限只约束新连接。 |
| AI 微服务配置 | 连接、鉴权用于后续请求，不表示搬迁服务；需要 AI 端应用的字段等待服务确认，必要时重启对应服务。 |
| 录像微服务配置 | 新存储先验证，失败保留原存储；存储/分段改变触发相关录制任务调整，配额由运行时读取。 |
| 告警微服务配置 | 重建连接与任务，可能短暂停止告警消费；启动成功后确认版本，失败走恢复路径。 |
| 大模型微服务配置 | 普通参数用于新任务，模型启停/加载异步完成后才确认；不能用保存请求成功代替模型就绪。 |
| 网络管理 | 走系统助手，直接应用，IP 更改带确认和超时回滚。 |
| 日期和时间 | 走系统助手；手动校时提示并重启 AI/录像以避免时间轴错乱；时间服务器单独应用。 |
| 授权管理 | 走专用授权流程，激活/移除后更新授权缓存。 |
| 远程协助 | 专用系统服务流程；本板未安装组件且未配置凭据，页面显示不可用，本轮未安装或打开远程入口。 |
