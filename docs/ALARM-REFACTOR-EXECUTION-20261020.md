# 告警触发与布防重构执行记录

## 已确认的产品边界

2026-10-20 用户明确选择“采用上述口径”：

- 几何位置判定使用底边中点；显示轨迹仍使用框中心。
- 接近距离按原始画面宽度百分比；计算距离时使用原图等比例坐标尺度。
- 生效时段支持星期选择。
- 同时显示触发次数和涉及目标数；跟踪目标数不等于实际人数。
- 本期不做声音、短信或推送；做待确认数量角标。

此前已明确：

- 触发器管理沿用 AI 通道卡片风格，创建和编辑使用四步弹窗。
- 不增加复制功能；不增加碰撞/进入子模式。
- 触发器定义不包含通道；在实时画面或热区上选用。
- 热区归来源通道，选用明确 AI 处理器；同一个触发器允许在同一画面多个热区选用。
- 热区、轨迹、推算框常显；工具放画面下方。VLM 仅预留。
- 草稿取消不写库，热区和选用统一保存；修改共享定义显示影响范围。
- 不主动提交；候选验证完成后再请用户确认部署。

上述确认不等于批准其他先前推荐的数量上限、30 秒活动时限等默认策略。
碰撞侵入作为单一行为的准确几何口径仍应在实现和测试前明确，
不能通过偷偷添加子模式解决，也不能把底边中点进入冒称物理碰撞。
