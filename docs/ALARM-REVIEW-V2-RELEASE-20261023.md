## 本轮实现

- 原有共享几何判定、防抖、活动去重保持；新证据来自同一个生产判定器。
- 检查点改为 before/start/last 等紧凑关键观测，不再累计逐规则 128 点轨迹。通道可选证据预算 512 KiB；待提交负载超过 7 MiB 时移除可选证据，核心状态仍受原 8 MiB 边界保护。
- 关键帧保留意图随 pending 协议持久化，稳定任务编号幂等写入；后台消费任务，删除完整检查点扫描。旧格式继续采用原重放读取方式。
- 原帧 JPEG 缓存迁到 /dev/shm/ainvr-review-frames，整机单进程共享 128 MiB、10 秒，写前淘汰，渲染队列仍为 2；命中关键帧才复制到 SSD。帧身份不一致或过期明确失败，不取邻近帧。
- 目标裁剪使用 VPU/GLES/JPU，1.5 倍外扩并扩展到 2:1，896×448；无 CPU 图像生产路径。
- 简短目标提示替代大段坐标 JSON；完整输入词元容量由原生分词器检查。无效图片、输入过长等永久错误不反复重试。
- 未取得可信验证资格时保留未审核，不修改确认/误报。资格校验需要 /etc/ainvr/review-validation.json 和 review-validation.pub：root 所有、不可组/其他写入、Ed25519 签名有效，并绑定模型哈希、布局、提示模板、两条阈值及版本、独立样本报告哈希和有效期。当前没有签发生产资格文件。真实数据库用例覆盖人工竞争和无效输入；硬件用例验证裁剪成功且未验证结果不能自动确认。
- 接近选用覆盖值沿用既有后端协议；布防新增百分比/像素联动的虚线接近带及拖动手柄。显示轮廓使用采样等距线，实际判定仍为原图像素的精确距离。
- 列表按通道、区域和一分钟时间桶折叠，审核对象仍独立；新增记录和既有记录状态变化分别提示。
- 详情提供原图、标记叠加和模型输入 JPEG 预览；配置增加超时、重试、审核图片配额；仪表盘显示任务和缓存指标。
- 删除无用的旧提示词坐标转换/轨迹摘要路径。保留旧证据兼容读取、离线回归工具和迁移。
