# YOLOE-26x 接入验收记录（2026-10-10）

## 产物和配置

- 目标：本项目 Jetson Orin、TensorRT 10.3.0；源文件 `ai-service/models/yoloe-26x-seg.pt` 保留。
- 检测版引擎约 111 MiB，安装目录 `ai-service/models/yoloe-26x-woman/`，包含原生 `model.engine` 及同目录产物清单。
- 固定文本 `adult woman`，标签 ID `woman`，展示名称“成年女性”；输入 640×640、保持比例补边、RGB NCHW /255、FP32 输入输出、FP16 计算优化。
- 新增开放词汇快速模型页面选项。文本和标签与已编译产物绑定，更换提示词需要新产物。

## 转换与测试

- 原始分割版与检测版在同图上使用 `adult woman`、`woman`、`person` 三种文本，检测分数完全相同，确认去掉蒙版分支保留检测行为。
- 官方样图在 `adult woman` 下最高分约 0.213，在默认 0.25 门槛下没有目标。因此数值对拍明确使用 0.1 门槛，验证两个目标的框和分数；不据此评价女性识别准确率，也没有降低生产默认门槛。
- FP16 原生 C++ 对拍通过：目标数量一致，框 IoU >0.90，分数绝对误差 <0.03，标签及查询字段一致，所有输出为有限值。
- 模型工厂 20 项（含显式启用的真机对拍）、配置 48 项、控制接口 60 项、SEI 9 项、延迟缓存 32 项、原有 TensorRT 对拍 4 项通过。
- 前端相关 73 项测试、类型检查和生产构建通过。不是全项目全量测试结论。
- `git diff --check` 通过，未执行提交。通道集成推流测试未运行，没有启动测试推流子进程。

## 两轮现场验证

均使用小门现有 4K H.264 输入，目标 5 FPS，原有逐帧截图、全景投影、亮度和归档配置保留；其它 AI 通道暂停，录像、流媒体保持运行。每轮约 90 秒。

| --- | --- | --- |
| 实际帧率 | 5.0 FPS | 5.0 FPS |
| 完成推理 | 458 帧 | 458 帧 |
| 推理平均 / p95 | 86.82 / 99.26 ms | 86.84 / 99.25 ms |
| SEI 来晚 | 5 | 0 |

第二轮有一次未匹配记录，不能称为所有推理帧都成功写入 SEI；需在后续长时运行中观察是否继续增长。已接收截图的账目闭合，没有本轮未保存目标。

两轮验证中大部分定时采样没有目标，少量目标在两次采样之间完成归档。结果只证明本段流上的配置帧率、转换一致性和实际归档链路，不代表密集目标场景的归档容量、最高帧率或性别识别准确率。
