# 告警列表：紧凑横条与单层详情

更新：2026-10-22。告警列表的当前布局与操作以本文为准；不改变行为分析、事件合并、统计和通知边界。

## 布局

一条目标活动占一个横条。桌面缩略图固定 96×72，窄屏 80×60；每条只取最高级别中最新的可用证据，没有时回退到最新有图阶段。其他阶段留在详情中，列表不铺开大图。图像保持比例，不裁掉目标。缺图显示占位，详情仍可打开。

中部显示来源/热区、最高行为、事件描述、绝对日期时间、触发器及紧凑的阶段经过。右侧排列确认、误报、详情，按钮至少 44px 可触控。窄屏只让操作区移到下一行，不恢复大卡片；文字可省略，完整内容在详情读取。

左侧保留来源筛选与今日概况，顶部保留处理状态、时间和行为。未确认默认全部时间，避免隐藏跨日积压。新告警仅提示刷新，不挤动当前阅读位置。

## 操作与跳转

| 用例 | 结果 |
|---|---|
| 点缩略图 | 打开同一详情窗，并选中该截图对应的阶段；不确认告警 |
| 点详情 | 打开最新阶段、证据、阶段时间线、处理备注与审计 |
| 切换阶段 | 当前详情内切换，缩略图不是嵌套按钮，不增加弹窗 |
| 查看录像 | 新页面打开原始输入通道、事件首末时间前后各 15 秒；保留告警列表。无有效来源/时间不生成链接 |
| 确认/误报 | 打开独立的小确认窗，核对记录、填写可选备注后提交；与详情窗为同一层的不同入口，不嵌套。不删除原事件或改变统计 |
| 确认已加载 | 打开一个独立确认窗，展示冻结的来源/时间/行为范围和数量，再提交明确的最多 200 个记录编号和处理版本；不会扩展到全库，不在列表插入表单 |
| 请求结果未确认 | 保留原操作编号及原批次重试；切换筛选不会改变已发批次。单条原操作未核对前不改处理意图 |
| 快速切换筛选 | 只接收最新请求结果；过期响应不覆盖当前列表 |
| 接口失败 | 保留已加载记录，明确错误并可重试；截图不可用不冒充无告警 |
| 关闭详情 | Esc/关闭按钮退出、焦点返回入口；Tab 在窗内循环，背景禁止滚动 |

## 实现

- `AlarmListPage.tsx`：列表读取、筛选、批次与处理状态。
- `AlarmRow.tsx`：紧凑横条和代表截图选择。
- `AlarmSheet.tsx`：单层详情、阶段证据、处理与录像入口。
- `EvidenceThumb.tsx`：仅可见时读取、最多四个并发；阶段选择中使用非交互图像，防止按钮嵌套。换证据编号时不闪现上一张图。
- `features/alarmNavigation.ts`：来源录像和有效时间段的纯函数。

本次仅需发布前端，不调整数据库或重启 AI、录像、流媒体及告警服务。验收时不对生产告警执行确认/误报，仅操作筛选、详情、证据及录像；处理写入、超时重试和批量部分成功由隔离测试验证。

## 复审修正（2026-10-22）

单条确认结果未知时，保留完整原请求（告警版本、备注、处理方式和操作编号）。关闭重开后显示原备注并锁定，明确提示重试上次操作；从另一处理入口打开也仍然重试原请求。已知结果返回后解除待重试状态。批量确认焦点循环支持按钮、输入、选择框和链接。
独立行为统计入口已移除，旧地址转到告警列表；流量统计及计数器管理继续保留。
