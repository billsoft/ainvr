# 开放词汇执行器部署与运行约定

## 产品行为

- 开放词汇通道新建时不预填业务识别对象。描述、稳定标签 ID、显示名称由用户填写。
- 描述驱动真实识别；标签只用于展示、检索与后续匹配，不替代识别描述。
- 高速模型使用 YOLOE-26x 原始权重进行 GPU FP16 推理，可修改描述。高级模型使用 LocateAnything-3B 的 FP16 引擎组合及运行时文本，不是 8B。
- 保存描述或生成上限前，执行器检查真实文本容量。过长描述不截断，也不保存为假成功配置。高级模型的字符上限不等于 token 容量。
- 描述、标签对下一次开始的识别生效；已经执行中的帧保留其原配置。换模型重启本通道。旧固定文本引擎只保留兼容，标签变更需重启。
- 每个通过通道阈值与最大目标数配置的识别目标都走归档；归档等待降低本通道实际帧率，不改成按秒存图。高级模型没有检测置信分数，保存 null，不伪造为 0。
- 两个执行器服务可以同时开启，但本设备仅保留一个开放词汇模型实例。停止通道释放模型；启动另一模型前停止原通道。保存配置和待机服务不加载 GPU 模型。

## 离线包

业务包包含执行器字节码、启动脚本、服务单元、已验证虚拟环境的附加依赖与运行契约。构建需要两个规范环境：

```
ai-service/runtime/yoloe/venv
ai-service/runtime/locateanything/venv
```

模型仍在独立模型包中，未变化时沿用已有包。不得把生产 env、密钥、socket、lease、数据、整个 out 目录或虚拟环境的绝对路径复制进发布包。

新板先按从零部署手册准备 JetPack 6.2、匹配 CUDA/TensorRT 和已验证的 ARM64 Python 3.10/PyTorch 基础环境。附加依赖从业务包离线安装；不是把桌面电脑的 Python 环境搬到 Jetson。安装器检查 Python、架构、PyTorch 契约及关键模块，失败时明确拒绝部署，不联网补包。基础环境路径可通过 `PROMPTED_BASE_PYTHON` 指定。

高级模型的模型包需要 tokenizer、vision、36 个 decoder、对齐 head、embedding 及 parity 验证文件；高速模型需要 `.pt` 权重和离线文本编码器。引擎与设备平台不匹配时必须重编译。

## 验收

1. 启动两个执行器，未启动开放通道时不出现模型加载日志，不占用模型级显存。
2. 保存短描述成功；超过真实容量的描述返回可读错误，持久配置不变。
3. 启动高速通道，检查 FP16、坐标范围、真实分数与用户标签。修改描述后实际目标变化，不能只替换标签。
4. 停止通道后出现释放日志，启动高级通道成功。另一开放通道仍运行时拒绝第二个模型。
5. 检查归档 delivery 接收、提交、待处理、隔离、删除账目；故障与隔离分别观察。
6. 检查输出视频持续增长、SEI 注入与迟到计数。高级模型需要延迟缓冲；网络高码率与容量限制仍可能造成迟到，不能承诺任何码率都不丢。

本次变更保留真实验证资料。日期验收文档是历史证据，不作为当前固定提示词约束；当前动态方案以本文件和开放词汇设计文档为准。
