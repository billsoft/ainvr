# 本机运行与外置历史存储：交付状态与后续接口契约

## 已部署并验证

- 参数库、程序、运行环境、HBM、Qwen 分词器/嵌入/归一化文件位于系统盘。此前已经用独立服务挂载命名空间拒绝 SSD 访问，并停止 Mongo 验证 AI 与 Qwen 仍运行；尚未物理拔盘冷启动。
- 当前外置盘由 fstab 中的文件系统 UUID 挂载到 `/mnt/ainvr-ssd`，不依赖 nvme/sda 的枚举名称。这个路径是逻辑挂载点，不是硬盘型号。
- 系统助手只读枚举块设备，按 UUID 返回身份；排除系统盘及其同盘分区、只读卷、重复 UUID、不可读取卷。未挂载卷仅展示，不擅自挂载。
- 仪表盘与数据库配置显示系统盘和外置磁盘的容量、可用空间、接口及挂载点。30 秒刷新，不在页面后台轮询。
- 录像配置可以选择已挂载磁盘并浏览目录。浏览不保存配置，点击使用目录才修改草稿，统一保存后生效。不通过链接穿越系统盘，不展示文件内容。
- 录像外置目录缺少有效读写挂载时，验证和启动新录像失败，不静默创建同路径目录写入系统盘。现存进程对突然拔盘的 I/O 失败仍由录像器的熔断/恢复机制处理。

## 容量政策与不能过度承诺的地方

| 内容 | 限制 |
|---|---|
| systemd journal | 256MiB 持久日志，单文件32MiB，保留至少2GiB空闲；运行日志64MiB |
| Docker生产容器日志 | 每文件10MiB，3份；SRS非阻塞缓冲4MiB |
| 系统文本日志 | 每文件16MiB触发轮转，4份，每5分钟检查；这是轮转阈值，不是硬磁盘配额，突发日志可暂时超出 |
| AI诊断日志 | 原有有界轮转，现位于本机AI配置目录 |
| 观测日志 | 每通道64MiB/10000条；本机可用空间低于2GiB拒绝新记录，保留原偏移身份并计入拒绝数 |
| 归档失败重试 | 原有1GiB上限及5GiB可用空间保护，不用无界重试填满系统盘 |
| 资源采样历史 | SQLite页数限制及1–168小时保留，日志每源按配置轮转 |
| 参数配置历史 | 最近1000个版本，额外保留服务applied/desired正在引用的版本；最近10000条审计，业务配置/密钥不删除 |

这些限制不等于“所有进程已证明无内存泄漏”，也不能限制管理员手工放入的构建输出、测试样本和回滚备份。系统盘仍需容量预警与持续监测。PostgreSQL自动清理会复用空间，但不承诺立即缩小已有数据库文件。该板可用空间约4.9GiB，不适合作为历史盘。

## 尚未交付：统一历史卷管理

当前 Mongo、告警证据、识别历史与录像索引仍使用已有部署的历史路径。数据库页面新增的是容量展示，**不是已经实现 Mongo 数据目录在线迁移**。不能把修改连接串当成换盘，也不能把只读磁盘发现宣称为自动挂载。

下一阶段应实现独立的宿主机存储控制器，前端只提交稳定卷ID与操作，不提交任意系统路径/命令：

1. 系统配置增加“存储与归档”，显示当前卷UUID、挂载、读写、容量和历史服务状态。录像可独立选择卷，参数库固定本机。
2. 未配置历史卷的新机器：发现磁盘后由管理员选择UUID，预检文件系统、读写、容量和唯一身份，再初始化专用子目录、原子写入挂载配置。多盘时不猜；不自动格式化，不自动接管有内容的陌生磁盘。
3. 已有历史卷换盘：形成预检计划（源/目标UUID、容量、待复制字节、受影响服务）；独立异步任务停写、复制、校验、更新配置、启动并健康检查。保留源数据，失败回退。不能在普通HTTP请求中执行长时间复制。
4. Mongo目录只能离线一致性复制或使用受支持的备份/恢复流程；不能复制正在写入的WiredTiger文件。同时处理告警证据、识别历史、录像索引与录像路径归属，不留下数据库指向旧图片的半迁移状态。
5. 操作状态持久化在本机，单飞锁、步骤日志、断电恢复、目标盘再次核对；UUID重复、系统盘、同源目标、空间不足拒绝。删除源数据不是迁移的自动步骤。
6. 冷启动缺盘：本机核心服务启动，历史能力明确为不可用；插回匹配UUID后启动历史服务。不会把其他USB盘当成原盘，不能在空挂载目录初始化新的Mongo。
7. 接入测试覆盖第二块真实SSD/USB、同名不同UUID、重复UUID、拔盘/重插、只读、满盘、迁移中断与冷启动。当前没有完成这些实机测试。

## 格式化建议

本轮不提供格式化接口，也没有格式化磁盘。后续若提供，应放在存储维护的高级操作中：管理员重新验证密码、展示设备型号/序列号/容量/UUID、输入确认文字，执行前再次核对物理设备身份；系统盘及其全部分区、正在使用的历史/录像盘一律拒绝。必须先解除使用并说明全部数据永久丢失。格式化中断只能显示失败，不能假装成功或自动重试破坏其他盘。新盘优先在交付阶段初始化，普通录像配置不应带格式化按钮。
