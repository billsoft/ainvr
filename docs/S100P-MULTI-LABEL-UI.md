# YOLOE 多标签配置与验收

日期：2026-10-13。开发目录 `/home/sunrise/ainvr`。

## 页面行为

AI 通道 → 编辑或新建 → 模型与推理 → 开放词汇。

- 已验收模型显示为「开放词汇识别 · 8 槽」，支持 1～8 行。
- 32 槽独立保留候选入口，当前禁用并标注「编译与验证中」。生成 HBM 不等于可以启用；必须通过板端质量、性能和完整链路验证。
- 每行包含识别描述、标签 ID、标签名称。描述决定检测语义；ID 用于结果关联，名称用于展示。改名称不自动更改 ID。
- 添加标签清除当前筛选并聚焦新行；达到槽位上限时禁止继续添加。
- 搜索在描述、ID、名称中匹配，只影响显示；保存仍提交全部行。
- 删除支持撤销最近一次删除，至少保留一行。删除配置不会删除已有归档记录。
- 桌面与平板宽屏采用列布局，窄屏采用卡片；输入与按钮高度至少 44px，支持鼠标、触屏和键盘 Tab 顺序操作。
- 空描述、空 ID/名称、重复 ID/描述、超容量会阻止下一步。切换小容量模型保留所有行，由用户明确整理，绝不静默截断。
- 修改在最后一步保存后生效，重新加载通道；关闭向导放弃未保存的编辑。

## 接口与兼容性

`model.prompts` 为有序数组，每项是 `description`、`label_id`、`label_name`。
前端保留旧单标签配置的读取和首次迁移；原有 label ID 保持不变。
原生服务配置解析、序列化、BPU 文本编码、检测结果标签映射均支持该数组。
切换固定类别模型使用 `prompts: null` 清除旧开放词汇配置。
模型名称的槽位限制与加载时 HBM 契约检查分别执行；32 槽候选不能替换已有 8 槽 HBM。

文本编码与 RepRTA 仍复用已验证的 8 批处理路径，32 槽分为最多四组。未使用的槽位清零；不重新合并已拆分的分词嵌入表。
