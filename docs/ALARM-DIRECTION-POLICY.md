# 告警行为参数与方向条件

2026-10-19，源码已实现并经隔离测试；未完成现网和真实浏览器验收。

## 用户操作

告警分析 → 监控行为 → 各行为参数与方向（可选）。每种选中行为可设置独立持续时间；不单独修改时继承默认值，使用默认按钮可取消覆盖。

方向条件分别选择区域/接触方位、进入方位、离开方位或运动方向。钟面快捷选择 12 个方向，也可直接填写角度和 ±容差。画面上方为 0°/12 点钟，右侧 90°/3 点钟，下方 180°/6 点钟，左侧 270°/9 点钟；不是地理方位。

保存前摘要展示条件，活动告警详情展示实际发生的方向。出现不支持方向条件；接近/接触支持区域方位与运动方向；侵入支持进入方位与运动方向；穿越支持进入、离开与运动方向。

## PG 监控器协议

behavior_settings 为按行为编码的可选对象，每项接受 duration_ms 和 direction_filters。未选中的行为不能携带参数。PG 版本历史保留完整配置，发布时展开为各行为的执行规则；未设置覆盖则沿用监控器默认 duration_ms。

示例：左进右出且区域内停留至少两秒：

```json
{
  "behavior_settings": {
    "region_traverse": {
      "duration_ms": 2000,
      "direction_filters": [
        {"reference":"entry_side_deg","center_deg":270,"half_width_deg":30},
        {"reference":"exit_side_deg","center_deg":90,"half_width_deg":30}
      ]
    }
  }
}
```

执行规则 direction_filters 与该列表一致。reference 还可取 region_side_deg、motion_heading_deg，具体支持项依行为限制。最多三个，参考字段不可重复；中心角 0–360°，容差 0–180°。角差使用圆周最短距离，因此 350° 与 0° 相差 10°。

## 语义与边界

- 多个条件同时满足才匹配，未设置或空列表不限方向。
- 设置了条件时，未知方向不匹配；即使容差 180° 也不把未知当作已知。
- 候选方向在触发时冻结，持续时间确认后沿用，不能用之后的转向替代先前的进入方向。
- 筛选失败的候选不变成统计事实，也不生成告警；不会因随后在区内转向而冒充一次新的侵入。
- 接触的区域方位为最近边界估计，不表示物理碰撞。穿越仍要求连续观察到完整外→内→外轨迹。
- 历史统计查询的方向筛选仍待实现；不要把规则筛选与查询筛选混称已完成。
