## 本期范围

- AI 服务只负责检测、跟踪、轨迹以及统一结果和原帧证据接口。
- 告警服务是独立进程；接收结果驱动计算，不为每条规则轮询视频或启动新进程。
- 四类行为：出现；接近警戒区；接触/侵入警戒区；穿越警戒区。接触和侵入分别编码。二维接触不能宣称物理碰撞。
- 区域穿越必须有同一目标可信的外→内→外过程，记录进入、离开位置与方向；不能用单条线的跨越代替。
- 标签是显式白名单，不选中的不监控；空列表不能启用。
- 短时预测不能单独证明侵入或穿越。断轨、遮挡、视频会话变化、几何/标签版本变化必须处理。
- 同一目标同一次活动过程内可有多个行为事实，但告警应按 episode 合并，不能每帧或每个阶段重复打扰。
- VLM 本期不实现模型加载、执行或调度验收，只预留接口及明确不可用状态。通知仍不实现。

## 数据分层与权威来源

- PostgreSQL：警戒区和监控规则版本、参数配置。无需额外空间数据库；普通二维几何计算即可。
- MongoDB：独立 behavior_events 行为事实、alarms 告警、处理/审计及必要消费恢复状态。
- SSD：图像证据。数据库保存原帧绑定引用；不能拿当前截图冒充事件帧。
- PG 区域和监控器存储、版本历史及规则快照发布已实现；Mongo 仅保留运行快照及旧规则兼容路径。现网配置发布尚未验收，旧写入代理仍需收口。
- 区域坐标为原始画面归一化坐标。画面视野、裁剪、旋转改变需要重新确认区域。

## 行为事件协议

schema_version、event_id、event_type、channel_id、input_stream_id、stream_session_id、track_id、label_id、zone_id/version、rule_id/version、episode_id、started_at、occurred_at、source_pts_ns、frame_id、direction、evidence_refs、quality。

event_id 在重放时不变；记录不携带告警确认状态。告警通过 behavior_event_ids 引用，不反向改写事实。未知 started_at、episode、方向、轨迹完整性必须为 null，不能编造。

方向区分进入/离开位置方位与运动朝向。画面上方 0°/12 点，顺时针增加；角度应按原图宽高计算，不能把归一化的矩形画面误当正方形。区域重心方向无法表示时必须说明限制。

## 统计口径

- 发生次数：同一事件 ID 只计一次；同一目标重新触发后可以有第二次。
- 跟踪目标数：channel_id + stream_session_id + track_id 去重，不称为独立真实人数。
- 默认按 occurred_at 使用 [from,to) 时间范围，统一 UTC 存储；显示按用户时区。
- 同一次活动接近、侵入、穿越分别计数，不能相加称为人数。
- 告警确认、合并、屏蔽、误报处置不隐式删除原始行为统计；未来人工排除统计必须另有审计口径。
- 输入覆盖未知/断流/积压时报告完整性，不将缺失数据补零。
- 先基于行为事实查询；分钟/小时汇总可重建，不以易重复累加的计数器作为唯一来源。

## UI

实时预览：独立警戒区显示开关、编辑按钮，矩形/多边形、顶点拖动、撤销取消、命名保存、接近范围预览。
规则：来源通道/区域/标签白名单 → 行为/持续时间/方向/去重及重新触发 → 名称/级别/生效时段/启用。
出现允许全画面；其他要求区域。模型切换导致标签失配必须提示修正。
告警一行一条，单条/批量确认独立弹窗，iPad 触控及键鼠均验收。
统计查询按时间段、通道、区域、标签、行为和方向筛选；区分次数与跟踪目标数。
