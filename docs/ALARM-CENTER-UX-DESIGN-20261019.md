# AINVR 告警中心：页面、交互与服务契约

日期：2026-10-19。状态：待确认的产品设计，不代表功能已实现或部署。

## 1. 范围与交付边界

当前跟踪阶段继续独立验收：统一跟踪结果、轨迹、实时预览绘制。本文定义下一阶段告警分析、可选复核、告警列表及人工确认。通知仅预留契约，不实现短信、邮件或外部发送，也不新增定时任务。

所有视频通道仍由接入管理创建。告警规则选择已有 AI 处理器，关联其源 SRS 通道；不创建 SRS 通道，不另拉流重复检测。预览坐标与证据绑定原始输入画面，而非播放器显示分辨率。

本期建议默认入口为“告警列表”；导航展示顺序为“告警列表 / 告警分析 / 告警复核”。复核是可选策略，默认关闭。未完成的行为能力不展示为可用；开发预览与生产导航分离。

## 2. 页面与完整交互

### 2.1 告警分析：列表与规则编辑

规则列表列：名称、AI 处理器/来源、目标标签、行为、布防时段、复核策略、运行状态、最近触发、操作。运行状态分草稿、启用、暂停、来源离线、配置失效、处理滞后。后两类必须显示原因，不能用“运行中”掩盖。

操作：新增、编辑、复制为草稿、试运行、启用/暂停、归档。已有告警引用的规则不可物理删除；归档后保留版本和历史引用。暂停不删除事件，也不取消已经产生的复核任务。

编辑采用三步，右侧持续显示自然语言摘要：

1. 来源与对象：规则名称、已有 AI 处理器、语义标签、行为。显示跟踪能力、源分辨率、有效采样率、最近数据时间。来源离线允许存草稿，禁止依赖实时画面的试运行。模型标签变化使规则配置失效，需重新映射，不能按同数字 class_id 自动沿用。
2. 空间与条件：按行为显示区域/线段/无需几何。画布可放大、拖顶点、撤销、重画、清空；鼠标与触屏均可用，另有坐标输入。预览支持检测框、轨迹、区域分别开关。线段起始建议在画面宽度 70%（中心向右 20 个百分点），不是固定保存值。显示方向箭头、A/B 两侧及交换方向。区域至少三点、无自交、面积非零；线至少两点且非零长度。保存 normalized_xy 坐标及源画面方向/裁切信息，拒绝画到黑边。视频构图变化后提示重新确认布防，而非仅按新分辨率盲目缩放。
3. 生效与复核：时段（含跨午夜、明确设备时区）、严重级别、事件合并条件、复核策略。关闭复核即跳过，不要求安装大模型。开启时必须选择可用策略；模型不可用可存草稿不可启用。保存已有启用规则产生新版本，生效边界明确，旧事件保留旧快照。

离开脏表单提示保存草稿/放弃/继续编辑。字段错误就地显示并聚焦首个错误；服务失败保留全部输入。版本冲突显示服务器版本，禁止静默覆盖。

“试运行”在用户选定的有限时段/片段上展示命中时间、证据轨迹、匹配条件与未触发原因，不写正式告警、不发通知。实时数据断流时明确停止，不把静止最后一帧当成有效观测。试运行结束由用户显式启用规则。

### 2.2 行为定义，避免误解

| 行为 | 最小依据 | 关键边界 |
|---|---|---|
| 出现 | 被检测支持的确认轨迹满足持续条件 | 重连后已有目标是否算新出现按规则明确配置 |
| 接近区域 | 距离进入外侧缓冲带，且满足时长/可选趋近趋势 | 默认像素归一化距离；未标定不可标“米” |
| 接触区域 | 选定目标几何与边界/区域相交 | UI 称接触或相交，不宣称真实物理碰撞 |
| 进入区域 | 可靠观测从外到内并满足滞回 | 开始跟踪时已在内部不补造进入 |
| 穿越线 | 有序轨迹从 A 到 B 穿过有限线段 | 要求时间间隔/缺帧限制；预测点单独不足以触发 |

这些行为可有关联，但不是全局必然包含。穿越线不必然进入任意区域；目标框相交不代表碰撞。每条规则只发自己定义的事件。同轨迹、同规则、同一次行为合并；跨规则关联同一 incident_id 可后续扩展，不隐式连发五条告警。

轨迹基准默认人员脚点/其他目标框底边中心，允许按场景选框中心或框相交；在规则快照中保存。跟踪预测用于关联和显示，证据记录 detected/predicted 与最后观测时间。失联过长/会话变更/PTS 回退清理状态，不跨断点推断进入或穿越。

### 2.3 告警复核：策略与任务

策略页：名称、模型及版本、适用行为、复核问题、证据要求、超时处理、启用状态、最近成功/错误。可新增/复制/保存草稿/样本测试；有历史引用的策略归档不删除。

模型选择仅展示已安装、芯片兼容且验收通过的模型；其他候选显示不可选择原因。开关关闭时折叠高级项，明确“分析结果直接入待处理列表”。关闭策略只影响后续事件，历史及进行中任务使用冻结策略。

证据默认全图+目标局部图；复核对象是否存在可单图，运动行为必须多帧带原始时间戳。缺证据返回无法判断，不让单图模型推断方向。问题模板引用事件、标签、区域和证据 ID。提示词不是可执行命令。

输出 supported / not_supported / uncertain，加简短原因、引用证据 ID、限制。没有校准依据时不生成置信百分比。非法 JSON、超长/截断输出、缺图、超时都进入失败/待人工，不当作不支持告警。

任务列表：排队、执行中、支持、不支持、无法判断、失败。可按事件看每次尝试、耗时、模型哈希、结构化输出。重试新增 attempt，不覆盖旧记录。低优先级串行执行、队列有上限；满队列保留事件并标待人工，避免拖垮检测/跟踪。资源不足不抢占录像。

### 2.4 告警列表与日志

默认待处理：未人工确认、且复核非明确不支持的事件；包含复核中、跳过、失败、无法判断。另有全部/已确认/复核不支持快捷筛选。过滤：时间、来源、规则、行为、级别、复核结论、人工状态。分页或游标，稳定排序；新告警显示“有 N 条新记录”按钮，不强制顶走用户正在看的记录。

列表必须一行一条告警，不变成长卡片。核心列：选择框、时间、来源、行为、复核状态、人工状态、详情/确认。规则、级别和证据放详情，宽屏可选显示附加列；默认不放大缩略图。鼠标行高约 48px；检测到任何触屏能力时约 56px，兼顾 iPad 接键盘鼠标的混合输入。iPad 竖屏保持单行；手机宽度不足时只在表格区域横向滚动，整页不得横向溢出。无记录/无权限/接口失败/断线四种状态不能混为“暂无告警”。时间展示时区；排序使用事件发生时间，另显示接收延迟。

详情采用右侧面板；窄屏独立详情页，返回保留筛选、页码和滚动位置。包括：原图与局部图、原始录像时间定位（可用才显示）、检测框/轨迹/区域开关、触发条件及规则快照、事件首末时间、来源及会话、复核结论及证据、人工处理、按时间排列的操作日志。图片加载失败/过期明确提示，不用实时画面冒充历史证据。

“确认已查看”：按用户最新要求，单条和批量均打开独立模态弹窗，不在列表下方插入表单、不挤高行。弹窗显示单条时间/来源/行为或批量数量、可选备注、取消和确认。其意义是接手，不代表检测正确；记录操作者/时间。原生 dialog 或等效无障碍实现阻止背景操作并限制焦点；初始焦点在取消，Esc 取消，关闭恢复触发按钮焦点；成功后若该行已移出当前筛选则回到列表工具栏。点击遮罩不提交。Tab/Shift+Tab 导航，空格勾选，按钮 Enter/空格激活，备注 Enter 换行，禁止全局 Enter 意外提交。勾选不重建行 DOM，保留键盘焦点。本页全选仅作用于未确认记录，提供半选态。触屏按钮和勾选标签至少 44×44px，输入字号至少 16px，不依赖悬停和双击，按钮不重叠。独立“标记误报”要求原因，保留原事件和复核结论；撤销误报或纠正确认记录为新审计操作，需要相应权限。

批量：勾选行或“本页全选”，工具栏显示数量；全筛选结果需额外点击并确认固定查询快照和总数，不能把本页勾选悄悄扩展全库。跨筛选自动清选。批量提交显示成功/已处理/冲突/无权限/失败数量，可只重试失败项。已确认记录重复提交幂等，不改变原确认人。复核运行中仍可确认；晚到复核只追加结论，不回滚人工状态。

日志是详情内完整审计，也可在列表切换“操作日志”视图：事件 ID、动作、操作者/服务、时间、原因。日志追加不可覆盖。所有告警（包括复核拒绝和误报）均可在全部记录找到。

### 2.5 权限和异常

观察者可看授权来源与证据；操作员可确认/标记；管理员可编辑规则和策略。前后端均做来源范围授权，不能只隐藏按钮。证据链接有访问控制。无模型、数据缺口、落后、存储失败、任务积压均显示显式状态；不得静默转 CPU 推理或把复核失败当正常跳过。

## 3. 服务拆分与数据流

建议新增 ainvr-alarm-service，包含规则引擎、事件管理、复核调度三个内部模块；VLM 推理由独立执行器提供，未来通知单独服务。现有 AI 服务只负责检测跟踪、发布统一帧数据、提供证据，不承担告警业务状态。

数据流：AI 统一跟踪结果 → 可靠事件输入 → 规则分析 → 持久化告警+待执行任务 → 列表可见 → 可选异步复核 → 人工处理。通知服务以后消费资格已满足的告警，不能从视频 SEI 反解析作为唯一业务输入。

当前 /results/latest 和有限结果环形缓存不是可靠消息队列。新输入必须有 channel_id、stream_session_id、seq、source_pts_ns 字符串、captured_at、模型版本、尺寸/坐标说明、语义标签、track_id、观测/预测状态与 last_observed_pts_ns。track_id 仅在 channel+session 下唯一。服务按每通道有序消费、持久化 cursor；重复幂等、缺号显式 gap、重放可恢复；缓存过期无法补齐就清理行为状态并记断点，不能凭预测补造跨越。先实现有界 SSD outbox+游标/重放契约或等效可靠队列，不能用 latest 轮询冒充全量。

SEI 保持播放用途，载荷截断不得影响告警输入。不同模型经适配器统一标签/框/时间字段；无分数模型 confidence=null，不伪造高置信度。前端不成为规则判定的唯一执行者。

## 4. 持久化与状态契约

MongoDB：alarm_rules（版本化）、alarm_review_profiles（版本化）、alarms、alarm_logs（只追加）、alarm_jobs。大图和片段存 SSD，Mongo 保存受控引用及哈希/时间/尺寸；创建事件即固定证据引用和保留期，避免截图归档清理提前删掉。清理任务先解除引用再回收，证据过期有显式状态。具体使用事务还是 outbox 取决于现有 Mongo 拓扑；不能假设 standalone 支持多文档事务。无事务时用单文档事件内 pending_jobs + 幂等搬运/恢复器，保证落库后不会丢复核任务。

建议事件字段：schema_version、alarm_id、dedup_key、channel_id、input_stream_id、stream_session_id、track_ids、rule_id/version/snapshot、behavior、severity、started_at/last_seen_at/ended_at、source_pts_ns、evidence_refs、model_snapshot、analysis_evidence、review、handling、version。

三个维度独立：

| 维度 | 状态 | 转换规则 |
|---|---|---|
| 行为生命周期 | active / ended | 目标离开、超时或会话结束；人工确认不终止跟踪 |
| 复核 | skipped / queued / running / supported / not_supported / uncertain / failed | 无策略直接 skipped；重试有 attempt；晚到结果校验任务租约与版本 |
| 人工 | unacknowledged / acknowledged；disposition 可 unset/false_positive | 确认和误报分别审计，模型不得覆盖人工结论 |

dedup_key 含 rule_version、channel、session、目标及行为 episode；唯一索引防重放重复创建。alarm_logs 用操作 ID 去重。Job 有 lease、超时、有限重试及人工终态；重启恢复未完成任务，不能重复写成功结果。

API 建议（由现有认证网关代理）：GET/POST /alarm-rules；PATCH /alarm-rules/{id} 带 expected_version；POST /alarm-rules/{id}/dry-run；GET/POST /alarm-review-profiles；GET /alarms（游标和过滤）；GET /alarms/{id}；POST /alarms/{id}/acknowledgements；POST /alarms/{id}/dispositions；POST /alarms/bulk-acknowledgements（明确 ids 或冻结 selection_token）；GET /alarms/{id}/logs；POST /alarms/{id}/review-attempts。写请求带 Idempotency-Key，冲突 409、权限 403、证据不可用明确错误码。推送仅用于刷新提示，丢线后以持久数据补齐。

## 5. 通知预留

当前不显示可配置的短信按钮，不显示“已发送”假状态。未来 notification_jobs 以 alarm_id+渠道+接收人+发送轮次 唯一，不使用单个 sent 布尔值。资格规则明确处理 supported、skipped、uncertain、人工覆盖以及最大等待时间；通知失败不回滚告警，人工确认是否停止后续通知独立配置。新通知功能启用默认只覆盖启用后的告警，不批量发送历史积压。

## 6. 实施顺序与验收

1. 跟踪第一阶段独立完成及稳定性修复；跨会话轨迹清理、能力开关与实际一致。
2. 统一事件输入、缺口/重放/去重、证据固定；模拟输入先验收。
3. 规则编辑与试运行、服务端规则引擎；从出现/进入/穿越中只开放测试通过的能力。
4. 告警列表/详情/确认/批量/审计；关闭 VLM 也完整闭环。
5. 可选 VLM 执行器、队列及资源隔离；兼容模型实测后开放。
6. 后续单独开发通知。

必须验证：跳过复核可入列表；开启但无模型不可启用；超时/缺图转人工；VLM 不支持仍在全部；确认不改复核；复核晚到不取消确认；批量部分失败可重试；重复帧/服务重启不重复告警；断点/预测轨迹不制造穿越；旧版本告警可追溯；旧证据有保留策略；离线明确显示；权限越权被拒；320px/键盘可用；新功能未验收生产入口隐藏；录像和 AI 主通道不因复核拥塞受阻。

## 8. 本次交付说明

交互预览 alarm-center.html 为本地演示数据，可切换三页、过滤列表、选择告警、查看详情、单条/批量确认、改变布防示意位置、试运行、切换复核开关。它不请求生产 API、不创建规则、不启动模型。正式拖动多边形、录像回放、误报表单、权限、接口和持久化以本文为开发要求，不能把演示控件视为完成。
