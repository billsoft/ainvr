# 流量统计范围清理与紧凑布局（2026-10-23）

## 使用

先选择今天、昨天、近 7/30 天或自选范围。计数器标题栏的“清理本期数据”清理本期全部统计位置；分项行的“清理”只清理该关联。打开确认框时冻结计数器、关联编号和起止时间，采用 [from,to)；未来终点截到当前时间。确认前显示实际范围，取消、关闭和 Esc 均不提交。

仅删除范围内的计数通行记录；计数器、热区、关联、录像、告警和时段外记录保留。后续计数不暂停。删除计数器及其全部历史仍是另一项操作。

## 历史与一致性

取消关联保留旧关联记录，新增热区产生独立分项。查询按原关联有效时间和历史方向分类。修复无重叠查询区间反转及保存其他布防时改写已解绑关联结束时间的问题。实时总数更新会同步加入新位置，保留已有趋势，完整趋势仍按原刷新周期更新。

新增 /flow/counters/:id/clear，通过后台验证全部关联确实属于该计数器，服务端传递已认证操作人。分析服务 /v1/flow/clear 先持久化 flow_clear_operations 审计和时间范围，再物理清理事实；全部统计查询、实时标签、趋势和通行记录都排除已清理区间，因此崩溃、并发晚到或旧帧重放不会恢复已清理数字。失败重试使用原操作编号和原范围，不扩大删除。覆盖信息保留以继续说明原时段分析完整性。

删除台账不能按普通日志清理；它是防重放的一部分。单次查询最多读取 10000 条相关清理范围，超过时明确拒绝并要求缩小查询范围，不返回错误计数。

## 布局

减少标题、卡片和段落间距；无对比数据不占空行；位置状态和名称同行；单热区不重复展示表尾总计；趋势图高度由 192px 调到 160px。保留多位置筛选、分页、点击数量查记录、趋势切换和至少 44px 清理/确认触摸目标。摄像头名称独立读取通道配置，减少对实时识别目录的依赖。
