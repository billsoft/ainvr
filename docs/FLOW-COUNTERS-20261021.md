# 流量统计：计数器库 + 热区选用（2026-10-21）

替代同日的首版流量统计（计数器绑定隐藏的“穿过采集”触发器），首版文档已删除。

## 模型

| 对象 | 管什么 | 在哪里管 |
|---|---|---|
| 热区 | 只管形状 | 实时监看 → 布防 |
| 触发器 | 告警行为 | 告警触发页 |
| 计数器 | 数什么（目标）、怎么数（越过一条线 / 依次经过两条线 / 穿过整个区域）、分项（两个方向分别计或只计一个）、是否显示在场 | 流量统计 → 计数器 |
| 计数选用 | 某热区 × 某计数器 + 计数线位置与朝向（按热区边编号） | 布防，与“选用触发器”并列 |

- 计数器定义里没有任何画面信息；边编号、朝向只存在于计数选用。
- 一个计数选用编译成一条“仅统计”执行规则，规则编号 = 选用编号（`flow-` 前缀）。不再生成隐藏触发器，告警触发库里看不到计数器。
- “进/出”在查询时由同一条规则的通行记录分类：越线按穿过方向（向内/向外），双线与区域按进入、离开的**边编号**。通行记录里写入稳定边编号，拖动顶点不改变编号，计数不中断；增删顶点时只有被拆开或合并的边换编号，用到它的计数线在布防中标为“需重新设置”，未确认不能保存。
- 计数线有版本（`flow_counter_binding_versions`）：调整后从保存时起生效，以前的通行保持当时的进/出。布防里调整计数线时可明确选择“按新计数线重新统计”（只随那次保存发送，不存进选用），此后整段历史按新计数线分类。目标列表按计数器定义版本同样分段。
- 只改名称等不影响判定的修改保持执行版本，正在穿越的目标仍会计数；漏检保留时间等判定参数改变才升版本。
- 清空后重画的热区全部换新边编号，原计数线须重新设置；拖动、增删顶点按端点沿用未变的边。
- 一个计数器可选用到多个热区，统计页给出合计和各热区分项；热区重叠时提示可能重复。
- 计数器的通行记录不进告警活动，也不混入告警行为汇总（记录带 `counter_id`，告警行为汇总统一排除）。

## 页面

- 流量统计 → 流量概览：默认今天；今日计数约 2 秒更新，趋势每 30 秒刷新，页面后台暂停刷新；今天 / 昨天 / 近 7 天 / 近 30 天；每个计数器显示两个方向的数量、与上一同长时段比较、本期净流入（所选时段进减出，保留负数，不代表实际在场人数）、分时图、多热区分项；点数字打开通行记录抽屉，每条可跳到前后 20 秒录像。
- 流量统计使用单页卡片，新建和编辑在弹窗中完成，支持暂停、启用、删除。已有计数器不能改计数方式。删除会解除选用并清除该计数器的历史通行与覆盖记录，操作前说明影响；未完成时显示重试入口，不假报成功。
- 概览切换时段时只显示最新一次查询的结果；查询失败时清掉旧数字。
- 布防：热区卡片“选用计数器”，在画面上点边设置计数线（越线可翻转，双线先 A 后 B，区域依次切换进入/离开），箭头表示“进”。
- 实时监看：计数线和箭头始终叠加；小窗显示“进 N · 出 N”，放大时加计数器名称，有人通过时闪一下“+N”。

## 数据与接口

- 参数库迁移只增不删：`010` 新增 `flow_counter_definitions`、`flow_counter_definition_versions`、`flow_counter_bindings`（选用移除后保留为 `active=FALSE` 以便查历史）；`011` 补回首版的 `flow_counters` 两张表（回退到首版后端仍能启动）并新增计数线版本表。选用随布防文档 `counter_bindings` 保存，共用布防版本、全局锁和幂等操作。
- Web 接口：`GET/POST /api/flow/counters`、`POST /api/flow/query`、`POST /api/flow/records`、`GET /api/flow/live`。
- 分析服务：`POST /v1/flow/query` 接收“计数序列”（规则编号 + 目标 + 方向过滤 + 可选容忍）。每个热区按计数线、目标版本拆成若干段，只覆盖被选用的时段。覆盖记录每个选用最多 5 秒写一次，规则版本切换时补写上一段尾部；相邻覆盖段 1.5 秒内视为连续。首尾缺口只在后端明确给出容忍时忽略：刚生效的开头（规则启动）和仍在进行的结尾（写入延迟）各 30 秒，查询过去的时段不容忍。
- 主要代码：`backend/src/store/flowCounters.ts`（定义、选用、编译、进出分类）、`alarmArmingStore.ts`（保存与快照）、`routes/flowRoutes.ts`；`alarm-service/src/flow-statistics.mjs`、`flow-coverage.mjs`；前端 `pages/Flow/`、`pages/AlarmCenter/CounterBindingEditor.tsx`、`features/counterGeometry.ts`、`components/player/SavedZoneOverlay.tsx`。
