- FlowCounters 的录像断言确实遗漏 `autoplay=1`。改用 URL 参数断言，验证摄像头、开始/结束时间和自动播放，不依赖参数顺序，保持原有功能。

### 延续上一轮已上线的可靠性改进

基础告警与覆盖先写入，可选停留/热度批量写入有驱动及应用时限；失败保守记缺口并推进检查点，确定性 ID 保留重放幂等。模型标签版本写入停留事实并隔离查询；时间门槛按查询范围内观测时长计算，禁止未来片段泄漏。长停留触及访问片段配额后仍继续累计有效画面热度，预测 coast 不累计。固定历史范围刷新同步告警、计数器配置及区域观测。

## 2. 数据与接口变更

### 覆盖和告警

- `alarm-service/src/flow-statistics.mjs` 在既有覆盖状态旁增加实测区间计算，不改变原计数事实。
- `backend/src/routes/flowRoutes.ts` 保留原字段，追加每位置和计数器的覆盖详情。分母按已知绑定有效时长加权，不把不同位置的时间做并集。
- 复用 PG 的计数器状态及布防成员历史，已证实的暂停/解绑时间不计入分母。缺失、不连续或超出有界历史读取范围时不猜测。历史位置通过 `include_inactive=1` 明确读取，默认查询仍只返回活动位置。
- `POST /api/alarms/events/statistics` 代理到原告警服务；告警列表接受同样的有界 `locations` 配对，避免摄像头集合与热区集合做笛卡尔积。

### 平面图

- 增量迁移 `025_floor_plans.sql`、`026_floor_plan_tombstones.sql` 已由正常后端启动流程应用。
- `/api/floor-plans` 提供读取和有版本的幂等保存；删除保留墓碑，旧版本不能复活同一 ID。
- 本机草稿采用显式导入；失败、超时和版本冲突保留草稿。过时的保存重试返回冲突，不返回已经失效的底图引用。
- 平面图只保存展示布局；检测形状、名称及计数关系仍归原布防和计数器模块。
- 浏览和编辑共用同一画布：底图在规划坐标中居中，浏览时按底图和已规划内容自动适配容器，不被固定 16:9 空画布压小，所有图层等比例同步变换。存储坐标不变，已有框、图形及可见热度范围保留在视野内。规划框不填热度颜色，热力图作为单独 Konva 图层置于底图上、选择框下；布局编辑时不显示数据热度。
- 编辑器新增“预览展示 / 返回布局编辑”，使用同一份草稿、同一只读画布和当前真实计数；预览不会自动保存，不改变规划坐标，预览时隐藏绘图与属性编辑工具。竖版测试底图在实际浏览器验证后明确放弃，未写入服务器。
- 恢复 GitHub `ba43d3a` 原型的空间分布表达，用所选单一计数器/方向的真实计数生成平滑相对场；无计数不生成热度，不合并共享热区的不同计数器。图层只表示规划位置附近的计数强弱，不代表实际逐点活动分布。用户可调隐藏冷区阈值。
- 新写入需要有效外部存储，无系统盘回退。图片限制、挂载身份、路径及 JPEG 结构都有校验；浏览器负责图片解码验证。

### 停留片段

- 继续使用 `ObservationConsumer` 的 prepare → materialize → checkpoint 恢复链路及确定性 ID。
- 只用已确认、实际检测且允许事件的观测。最多跨过 1.5 秒短暂间断保留片段身份，间断时间不计入时长。
- 每片段最多 128 个合并的时间区间，最多 512 个活动片段；任意查询和分桶逐区间求交，不把整个片段跨度当作实际观测。
- 达到片段时长或区间数量上限时明确截断。派生数据超过 prepare 预算时暂停该视频会话的停留采集，记录缺口，保留原告警链路的预算。
- Mongo 新增 `region_dwell_visits` 有界滚动集合，数据预算 256 MiB、最多 500000 条。此预算不含索引和存储引擎开销；旧数据会按插入顺序淘汰，不承诺历史完整。
- `/api/flow/dwell` 返回观测下限、检查点时间、缺口、容量状态及保留范围。UI 显示中文异常和截断提示，不把片段数解释为人数。
- 旧的连续片段保持可读，既有碎片不回写合并；新算法只影响后续输入。

### 原画面热度

- 同一观测消费者把合格的相邻检测间隔分配到前一锚点所在网格；不新增推理、跟踪、拉流或图片存储。逐格值是离散时段的分配，不宣称精确逐格驻留时间；总量为已观测目标时长下限，多目标同时出现相加。
- Mongo `region_heat_minutes` 为限量滚动派生集合：64 MiB、最多 50000 条，最多 128 个未封存网格；共享 prepare 预算不足时先放弃热度派生，原计数与告警优先。
- `/api/flow/heat` 复用原服务和鉴权代理。只查询范围内完整封存分钟，明确返回实际起止范围，边缘不足分钟和进行中分钟不摊入；没有完整分钟时返回空范围，不补历史。
- 查询分批流式读取，最多 50000 行、64 个兼容坐标组、15 秒期限，超限明确失败，不展示截断合计。响应按来源、几何、画面尺寸、区域版本、锚点和模型类别版本分组。同口径的视频会话可累计时长，但不连接观测间隔或去重人员；旧记录缺少模型类别版本时单独显示。
- 前端保留原画面坐标网格、逐格读数、带语义的 CSV 和原来源录像入口。尚未标定摄像头到平面图的映射，不把画面网格强行投到规划底图上。

## 3. 关键交互修正

- 编辑平面图、查看记录、选择日期或分析某个区域时暂停页面自动刷新，避免编辑窗口被卸载、草稿丢失或查询结果每分钟清空。分析期间使用顶部刷新更新截止时间。
- 编辑器支持右上角关闭、Esc、草稿放弃确认、键盘焦点限制及关闭后返回入口。
- 放弃、导入和删除草稿使用项目已有确认弹窗，避免原生确认框阻塞浏览器；只有最上层弹窗处理键盘。
- 1366×768 的总览采用紧凑规律预览，提供 44 像素的“查看完整规律”入口；完整页支持逐格读取。
- 图表、排名、记录、CSV 沿用同一范围。抽屉的不可用方向显示“—”并禁用，不显示假零。
- 页面恢复原型的紧凑工具栏、细下划线页签及四个 KPI；总览左侧趋势/周规律，右侧热区/采集质量。详细口径放入可展开说明，覆盖不足保留一行可见提示。区域观测页采用两个独立面板，避免整页被说明文字拉长。
