# 告警触发需求 v3：已确认口径与当前交互（2026-10-20）

本节优先于下方保留的 v2 设计稿。v2 的像素距离、长按删点、画面上方操作条和卡片直接开关已被后续确认取代。实现状态、测试及部署限制另见 `ALARM-REVIEW-RESOLUTION-20261020.md` 和 `ALARM-REFACTOR-RELEASE-20261020.md`；不能把设计描述当成已通过验收。

## 已确认的分工与判定

- AI 服务提供检测、跟踪、轨迹和原帧证据；告警是独立服务；前端只通过控制台后端访问。参数库保存热区、触发器和选用，行为事实与告警使用已有记录库，不引入空间数据库。
- 四种行为：出现、接近、碰撞侵入、穿过。碰撞侵入没有额外接触/进入子模式；当前几何含义是从外向内跨界，不能宣称判断了物体物理碰撞。
- 判定位置是框底边中点；显示轨迹取框中心。接近距离是画面宽度百分比，按原始画面同一像素尺度计算，选用处允许覆盖。
- 出现按同一跟踪身份持续计时，允许受限短时预测维持连续性，只在真实检出时确认；预测/低置信显示框不构成跨界证据。首次在区域内出现不自动构成侵入。穿过需要完整进出证据，同边返回不算。
- 只记录实际配置并生效的触发器所产生的事实。统计区分触发次数与涉及跟踪目标数，后者不等于实际人数。时段支持星期与时区，统计支持本地时区分桶。
- 同一活动的告警保留最高已触发级别，历史阶段可追溯；“仅统计”不生成告警。跟踪身份必须包含处理器及流代次，不能仅靠数字 ID 合并不同来源目标。
- 本期只做待确认数量角标；声音、推送及 VLM 执行不做，保留扩展接口。

## 配置模型与交互

| 对象 | 责任与入口 |
|---|---|
| 触发器定义 | 告警触发页的卡片列表；四步弹窗定义行为、目标、条件、时段和用途。不选通道、不提供复制或目标搜索。 |
| 热区 | 属于来源相机；从实时播放器下方“布防”打开参考画面编辑。 |
| 选用 | 整个画面只选出现；热区可选四类。允许多选触发器，每项单独确认 AI 处理器、方向、距离。只有一台兼容处理器时自动选择，多台时明确选择。 |
| 执行规则 | 按选用编号生成；同一触发器可以用于同一画面多个热区。 |

触发器目标提供可移除的已选区、常用与更多类别；选用位置显示来源及处理器名称。卡片上的“启停与归档”进入时段与用途步骤，保存前显示影响范围。所有修改仍通过弹窗保存，不提供立即写库的开关。

布防参考画面支持轻点或键盘选中热区，编辑、选用、移除等操作放在画面下方。矩形使用两次点选；顶点拖动、选边插点、删点和显式平移工具以触摸操作为主，不依赖悬停、双击或长按。方向按稳定边编号保存，进入边绿色、离开边橙色，参考画面同步高亮。

热区与选用共用一个本地草稿；批量选用全部配置完才原子加入草稿。最后一次“保存布防”事务提交；取消不写库。移除热区先展示受影响选用并确认，保存前可撤销。Esc 与取消保护未保存的外层草稿；保存结果不确定时锁住修改，以同一操作号重试。

热区及轨迹默认常显；推算与低置信显示框保持虚线。“识别框”开关统一控制真实框、推算框及低置信框；关闭框不关闭轨迹或热区。轨迹滚动保留最近约 5 秒。全景视图使用视频相机矩阵投影热区边界和轨迹；热区保留原图边界含义，轨迹跨 ERP 接缝选择连续短路径并裁剪背面。全景以边界轮廓表示区域，不填充平面多边形；已确认的全景来源可在全景参考视图中编辑，并反投影保存原图坐标；普通 2D 操作优先。告警判定始终使用原始画面坐标，不受观看视角影响，跨接缝跟踪连续性不作保证。

## 历史 v2 原稿（仅用于追溯，冲突条目以 v3 为准）

# 告警触发需求（合并版 v2，2026-10-20）

v1 中"触发器里选通道"的做法作废。新模型类比"权限 / 角色"：
- 触发器在触发器库里定义，只描述检测什么。
- 在实时监看画面上给通道、热区选用触发器。

本历史稿不再是唯一依据。标注 [默认] 的条目是用户未明确、按推荐方案定的，可以改。

## 1. 模型

| 概念 | 类比 | 内容 |
|---|---|---|
| 触发器 | 权限 / 角色 | 行为（四选一）、目标、条件参数、生效时段、用途。不含通道 |
| 热区 | — | 画在某个通道画面上的多边形，属于该通道 |
| 选用 | 给用户分配角色 | 在某个通道上，把一个或多个触发器选用到"整个画面"或"某个热区"上 |
| 告警 | — | 同一通道的同一目标只有一条，显示命中的最高级别 |
| 行为记录 | — | 每次命中都记一条，用于统计，不合并 |

对应关系：
- 触发器与行为一对一。
- 一个触发器可以被多个通道、多个热区选用，也可以只被一个选用。
- 一个热区或整个画面可以同时选用多个触发器。

## 2. 触发器库（"告警触发"页）

1. 触发器可以新建、查看、编辑、暂停 / 启用、删除（归档）。只读信息直接显示在卡片上，修改一律通过弹窗向导，用"保存 / 取消"关闭。
2. 向导分四步：
   1. 行为：出现、接近、碰撞侵入、穿过，四选一。
   2. 目标：上方是"已选目标"区；下方是常用目标，其余放在"更多类别"里展开。可单选或多选，不需要搜索。
   3. 条件：
      - 出现：持续秒数。
      - 接近：默认接近距离（像素），选用时可以按画面调整。[默认]
      - 碰撞侵入、穿过：没有额外参数，方向在选用时设置。
   4. 时段与用途：生效时段、仅统计或统计并告警、名称；底部一句话摘要。
3. 卡片显示：行为级别、名称、启用开关、一句话说明、目标、用途、时段、今天命中次数，以及"选用于"（列出通道 · 热区或整个画面，例如"大门 · 禁区，后门 · 整个画面"）。
4. 删除或归档已被选用的触发器时，在弹窗里列出受影响的通道和热区，确认后一并解除。

## 3. 实时监看：播放器底部工具条

1. 所有操作按钮都放在播放器底部工具条，与 360 全景、全屏同一排。
2. 工具条按钮（触控目标不小于 44 像素）：播放 / 暂停、静音、识别框、**布防**、协议、360 全景、全屏。
3. 删除：
   - 画面右上角的"显示警戒区 / 叠加区域"浮动按钮组。
   - "轨迹"开关。
4. 常显：
   - 热区和轨迹像识别框一样一直显示，不提供显示 / 隐藏开关。
   - 热区上标注名称，以及它选用的触发器（级别色块加名称）。
   - 整个画面选用的触发器显示在画面左上角的标签里。
5. 全景视图下暂不叠加热区和轨迹，并显示提示。
6. 宫格里的小画面只显示，不进入布防；点"布防"会先切到这个通道的大画面。

## 4. 布防模式（热区的新建、编辑、删除与选用触发器）

点工具条上的"布防"进入布防模式。

**进入时：**
- 画面定格为当前帧，便于触控画图；直播、录像和识别照常运行。
- 画面上方出现布防条：通道名、"新建热区"、"整个画面的触发器"、"完成"。

**新建热区：**
- 两种画法：
  - 多边形：逐点轻点放顶点，点第一个顶点或"闭合"按钮完成。
  - 矩形：按住拖出两个对角。
- 完成后弹出热区弹窗，填写名称并选用触发器。

**编辑热区：**
- 轻点热区：选中并显示顶点手柄。
- 改形状：
  - 拖动顶点手柄移动顶点。
  - 点边中点的"＋"插入顶点。
  - 长按顶点删除顶点（至少保留 3 个）。
  - 拖动热区内部整体平移。
- 键鼠：方向键微调选中的顶点，Delete 删除顶点，Ctrl+Z 撤销。
- 形状改动在"完成"或点"保存"时提交；可以撤销、重做。

**热区弹窗**（轻点热区后点"设置"，或新建完成后自动弹出）：
- 名称。
- 选用的触发器：从触发器库勾选一个或多个，四种行为都可以选，其中"出现"表示在热区内出现。
- 每个已勾选的"碰撞侵入 / 穿过 / 接近"触发器：在热区缩略图上点边设方向，默认不限方向。"接近"还可以拖动外圈，调整这个热区的接近距离。[默认]
- 删除热区：二次确认后同时解除它选用的触发器。
- 保存 / 取消。

**整个画面的触发器弹窗：**
- 只能勾选"出现"类触发器。需要热区的触发器在这里置灰，并说明"请在热区上选用"。
- 保存 / 取消。

**其他规则：**
- 没开目标跟踪的通道，或模型里没有触发器所选目标的通道，相应触发器置灰并写明原因。
- 热区或选用发生改动后，相关规则按新版本生效，原有的历史记录保留。

## 5. 判定规则（后端，沿用已上线的逻辑，按新模型调整）

1. **生成执行规则：** 每条"选用"生成一条执行规则：触发器 × 通道 ×（热区或整个画面）× 方向 × 接近距离。只有启用的触发器才下发。
2. **出现：**
   - 选用在整个画面上：按全画面判断。
   - 选用在热区上：目标在热区内连续出现满秒数才算（"出现"恢复支持热区，需要改引擎）。
   - 都按跟踪编号计时，补帧算连续，只在真实检出时触发，帧率自适应。
3. **接近、碰撞侵入、穿过：**
   - 方向用热区的边表示，越界必须有真实检出作证。
   - 原路退回不算穿过；侵入、接近要稳定离开后才能再次计数。
4. **级别与合并：**
   - 级别包含：穿过 ⊃ 碰撞侵入 ⊃ 接近 ⊃ 出现。
   - 同一通道的同一编号，跨所有热区、所有触发器只合并成一条告警。先报再升级，告警时间取首次触发。
   - 只有"统计并告警"的触发器参与告警。
5. **统计：** 每次命中都记一条行为记录，带触发器、通道、热区（或整个画面）、方向、目标和时间。可以按时间段统计，并按触发器、通道、热区、方向分组。

## 6. 数据（参数库）

- **触发器：** 在现有触发器表上移除"绑定通道"的部分，只保留定义。
- **新增选用表：**
  - 每条记录：通道、热区（为空表示整个画面）、触发器、方向（进入边 / 离开边）、接近距离（为空就用触发器的默认值）、版本。
  - 支持幂等和版本冲突检查，与现有热区、触发器一致。
- **迁移：** 已有触发器里的"绑定"，转成对应的选用记录。

## 7. 用例与交互步骤

| 用例 | 步骤 |
|---|---|
| 建一个触发器 | 告警触发 → 新建触发器 → 选行为 → 选目标 → 设条件 → 设时段、用途和名称 → 保存 → 卡片出现在库里，"选用于：尚未选用" |
| 给整个画面选用"出现" | 实时监看 → 点大门画面 → 工具条"布防" → "整个画面的触发器" → 勾选"前区有人" → 保存 → 画面左上角出现该触发器标签 |
| 画禁区并选用"侵入" | 布防 → 新建热区 → 多边形，点 4 个点后闭合 → 弹窗：名称"禁区"，勾选"门前侵入"，点下边设为进入边 → 保存 → 热区常显，并标注"禁区 · 碰撞侵入" |
| 同一个触发器用在多个通道 | 在后门画面重复上一步，勾选同一个触发器 → 库里该卡片显示"选用于：大门 · 禁区、后门 · 门洞" |
| 改热区形状 | 布防 → 轻点热区 → 拖动顶点或点"＋"加点 → 完成 |
| 删除热区 | 布防 → 轻点热区 → 设置 → 删除热区 → 确认 |
| 取消某个热区的触发器 | 布防 → 轻点热区 → 设置 → 取消勾选 → 保存 |
| 暂停触发器 | 告警触发 → 拨卡片开关 → 所有选用它的地方一起暂停 |
| 进出计数 | 建"穿过"触发器（仅统计）→ 在通道热区上选用，设进入边和离开边 → 在行为统计里按时间段、触发器统计 |

## 8. 隐藏条件

- **无效选用：** 热区画面规格变化（换相机、分辨率）后，热区和它的选用失效，界面提示重新确认。
- **触发器被修改：** 选用它的地方立即按新定义生效。
- **方向和距离：** 边的名字按画面位置命名（上边、左下边……），不是地理方向；接近距离按原始画面像素计。
- **人群密集：** 跟踪编号可能断开重建，"出现"次数会偏多；人流计数用"穿过"。
