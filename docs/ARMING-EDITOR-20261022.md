## 设计与布局

- 近全屏工作区，桌面四周留 16px，窄屏留 8px；取消固定最大宽度。图像等比适配，绝不拉伸或裁去可编辑区域。极宽图像在竖屏仍会有合理留白。
- 顶部始终保留布防工具和唯一的“保存布防”。绘制时下方出现绘图工具行，不再出现嵌套“保存区域 / 完成”。
- 画面只放紧凑名称、铃铛数量、计数数量标记，不展开遮住画面的操作卡片。标记在屏幕像素中避让，移位后用引线关联热区；空间不足可用顶部选择列表准确选中。
- 点击名称显示关联概览；点击数量图标：零项进入添加，一项直接调整，多项显示列表。形状、移除、添加和调整在同一检查面板完成。
- 横屏检查面板在右侧，竖屏在画面下方并限制高度；只有面板滚动，画面和顶部保存始终可见。
- 文字、边框、圆角和主次按钮沿用现有页面规范。图标配短文字；顶点显示小圆点，触控热区保留 44px。边编号与控制点分开显示。

## 草稿与退出

热区、触发器选用、计数器选用都属于同一个本地布防草稿。返回、切换对象或点顶部保存，会先校验当前编辑内容并并入草稿，不发送中间写入请求。无效内容保留并显示错误；可“撤销本处修改”退出当前未应用的编辑。

顶部取消放弃整份未保存草稿，有修改时只弹一次确认。Esc 先退出确认，再返回当前编辑面板，最后退出布防。移除热区仍需一次确认，列明受影响的触发器、计数器；确认也只修改草稿。

保存时一次提交；超时后锁定草稿并保留相同请求与操作编号重试，不能先修改再重发。修改热区导致方向失效时必须明确重新确认。

触发器库和计数器库是独立管理对象。布防里不再叠加新建计数器弹窗；提供新页面管理入口及“刷新库”，返回后继续原草稿。

## 操作用例

| 用例 | 操作与期望 |
|---|---|
| 新增热区 | 顶部新增，画多边形或矩形，改名；可直接保存布防或返回画面继续关联 |
| 调整形状 | 名称标记 → 编辑形状与名称；拖点、插点、删点、平移、键盘微调；几何校验保持原规则 |
| 重叠热区 | 点击画面或顶部选择列表；标记不展开大卡片 |
| 移除热区 | 面板移除 → 影响确认；可撤销，保存后才解除关联 |
| 整个画面关联 | 左上角画面铃铛 → 勾选出现触发器；不提供依赖区域的行为 |
| 热区多触发器 | 铃铛 → 勾选多个 → 同面板分别设置；不逐层点“下一项 / 确定” |
| 调整触发器 | 图标或列表进入原选用；更换处理器必须明确选择兼容项 |
| 方向重确认 | 热区边变化后显示告警，明确勾选确认；不能靠打开再关闭自动消除 |
| 添加计数器 | 计数图标 → 选择库中计数器 → 点击画面边或面板边号 |
| 单线方向 | 点边仅选择线；翻转必须点“翻转方向”，重复点同边不翻转 |
| 双线方向 | 明确设置 A / B，选择完成后不会因多点一次清空 A |
| 区域方向 | 先选进入 / 离开工具，再点边；边不能同时属于两组 |
| 历史统计 | 改方向默认保持历史；显式选择才重新解释历史数据 |
| 切换对象 | 有效修改进入同一草稿，无请求；无效修改阻止切换并提示 |
| 当前撤销 | “撤销本处修改”只丢弃当前编辑，已有其他草稿保留 |
| 全局撤销 | 返回画面后撤销或重做已并入的草稿操作 |
| 保存 | 无需先关闭设置，顶部保存先校验并提交全部修改 |
| 网络未确认 | 同请求同编号重试；禁止修改锁定中的草稿 |
| iPad | 控件至少 44px 命中；工具文字不依赖悬停；竖屏面板在下方 |
| 关闭 | 顶部取消，必要时一次确认；无中间保存 |
