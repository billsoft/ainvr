# 录像回放识别框

## 使用

在录像回放中选择 AI 输出录像，默认显示随录像保存的识别框、类别、置信度和关键点。播放器左上方可切换“隐藏识别框 / 显示识别框”。普通视频不重新调用 AI；没有 SEI 的时间不绘制识别框。原始下载文件保持不变，画框只是浏览器叠加层。

拖动、倍速、暂停均使用录像媒体时间：暂停时框跟随当前画面保留；跨段清空旧数据；显式空检测立即清框。未参与推理的帧最多沿用此前 300ms 的结果，不使用未来帧。

## 数据与复用

- 录像服务 `GET /v1/recordings/{id}/sei?from_ms=N` 返回一个 10 秒窗口，包含窗口前 300ms 的上下文。时间使用现有录像格式的样本 PTS，包含 composition offset，不是 SEI 中直播的原始 PTS，也不是系统时间。当前解析器不支持 `elst` 编辑列表的时间映射。
- 沿用 `mp4_samples` 读取分片 MP4 的元数据位置，跳过 mdat 图像数据；复用 `sei_worker` 的 H.264/H.265 前缀 SEI 解析。保留 `det: []` 与无 SEI 的区别。
- 前端与实时预览共享 `parseSeiJson`、`detectionDrawing`、`overlayGeometry`。回放使用 `requestVideoFrameCallback.mediaTime`；不支持时使用媒体元素的 currentTime。
- 前端缓存相邻三个窗口，并在窗口末尾提前读取下一窗口。旧请求在换段、关闭叠框或跳转窗口后失效。

## 资源和权限边界

- 每次最多读取 10 秒、返回最多 2400 条 / 2MiB 元数据，服务端最多缓存八个窗口。
- 读取在独立子进程中进行，5 秒超时；同一时刻最多一个读取进程，忙时返回 503。磁盘阻塞的子进程未退出前不再启动替代进程。不会在 HTTP 事件循环同步扫描录像，也不增加数据库写入。
- 使用现有媒体鉴权、授权校验、存储身份检查和配额读取保护。前端通过通用请求客户端传递鉴权头，不把密钥写入新接口地址。
- 识别信息读取失败时显示重试按钮，视频继续播放；错误不伪装成“没有识别信息”。
- 只支持现有录像服务生成的分片 MP4。未知或损坏的格式明确报读取失败。

## 发布与验证

更新录像服务 Python 源码并重启 ainvr-recorder，重建前端镜像；无需重启 AI、SRS、授权或数据库。重启录像服务会产生短暂录像间断，应在部署记录中说明。离线包下次构建需要包含新增的 Python 模块和新版前端。

测试覆盖 H.264/H.265、空检测、MP4 时间窗口、跳过图像数据、子进程超时及并发上限、鉴权、存储切换、暂停、拖动清框、显示开关及失败重试。上线抽查实际 SEI 接口、回放画框和四路录像恢复状态。
