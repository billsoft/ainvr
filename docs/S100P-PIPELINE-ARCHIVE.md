# AINVR real inference to durable prepared archive

ainvr_pipeline_probe accepts an optional new spool directory after the snapshot directory/projection arguments. For each real detection it renders a crop, generates a fixed ObjectId, builds the original/processed archive BSON and durably stages it before advancing. The probe uses a bounded 128 MiB/10000-record spool. Errors stop the offline run; this is not yet the live channel backpressure loop. Prepared records survive a later report/JPEG-sidecar failure.

FrameResult.timestamp is now the Unix time when the decoded frame reached the offline pipeline, measured before preprocessing/inference. It is explicitly not the camera capture time. Source presentation time remains frame_pts_ns. Probe records have epoch zero and a fresh spool; a production channel must use its current deletion journal epoch instead.

Run python3 test/ai_port/verify_pipeline_archive.py. Evidence: test/results/pipeline-archive-20261011_183052_993304/summary.json. Two actual YOLO26m CPU-inferred frames yielded ten screenshots. A separate process reopened the prepared spool, replayed it to an isolated Mongo test collection and verified all ten records. Image/original_image binary payloads equal the generated JPEGs exactly; class IDs and wall/source timestamps match the per-frame report. Replaying the empty spool again does not duplicate records. Test collection test_pipeline_20261011_183052_993304 retains ten records; pending count is zero. The old no-snapshot SCRFD/YOLO pipeline regression also passes: test/results/native-pipeline-20261011-183112-253180.

This joins hardware video decoding, hardware/GLES preprocessing, real CPU inference, crop rendering, hardware/CPU JPEG, durable prepared staging and independent Mongo delivery. It does not complete the live channel service, user-model NPU compilation, pre-encoding recovery, enhancement, licensing or retention/accounting requirements. No new production service was started by this test.
