# 国标音视频接入专项审查与验证（2026-10-27）

本期受限国标实时音视频接入开发和必要模拟验收已完成，R12网关、媒体策略和R12d控制台已部署。用户于2026-10-27明确取消24小时验收关口；双路长测合作停止、数据保留，不算24小时通过。真机仍缺失，不宣称完整国标认证；本轮不修改现有摄像头配置、SRS、AI 或录像服务，不自动提交或推送。

## 本轮修正

- 注册最小正有效期为 3600 秒，默认 86400 秒；0 为注销，Contact expires 优先。
- sipgo TCP 消息容量对齐 256 KiB XML 加独立头部预算，覆盖大于 64 KiB 的目录批次。
- 媒体桥接前及运行中核对 ZLM 实际 RTP peer，拒绝与协商地址不符的源。
- 网关重启盘点接收器并避让端口/SSRC，只回收本平台明确命名的孤儿会话；保留未知/旧命名监听器。失败端口轮换，SSRC 隔离两分钟，耗尽有界拒绝。
- TCP 首次连接加三次重连、间隔至少一秒；接收器五秒异步建连使用六秒 API 超时，普通 API 保留三秒。
- 不支持的视频编码即时分类；通道详情显示国标恢复原因、SRS 发布状态及实际音频处理。
- 发现并关闭 ZLM 默认自动补静音；否则“存在 AAC 音轨”可能只是 8kHz 人工静音。测试 PS 源同时修正初始 PSM 的音轨声明时序，新增真实音频内容校验。
- 分段抓取证明 ZLM 相对时间戳修正使样本产生约 256ms 固定偏移，SRS 与录像没有继续扩大。媒体策略改为保留源 PS 时间戳；安装器对现有 INI 按项更新并保留其他配置，不能只更新网关二进制。
- R10 补齐目录项厂商、型号、父节点和状态等保留字段的 512 字节产品容量限制，并拒绝重复标量覆盖。先用未修复引擎复现，再运行修复后竞态回归；这是资源边界，不声称标准为这些 string 字段规定了 512 字节。
- R11 为所有设备的目录缓存与刷新工作分别增加 32MiB 的保守计量预算；超额返回 SIP 503、保留原目录并释放部分刷新。已有目录可以使用独立刷新额度原地替换。逐条目录合并改为先验证小批次、原子提交，避免反复复制整张目录。
- Opus 实际输入揭示旧桥接仅禁用输出音频，仍被输入音频分析拖住，视频无法发布。R11 保留 FLV 视频时间戳路径，明确禁用输入音频并限制分析窗口；两版 H.264/H.265 四组真实降级测试通过，不转码视频。
- R12 根据 2022 A.2.6.6、2016 A.2.6 的设备状态应答区分注册连接、Online 和工作 Status。旧代码接受非法工作状态且未保存自检故障，已先用两版 UDP/TCP 实际报文复现。修正后，健康心跳不能清除自检故障，自检恢复也不能清除心跳故障；目录容量恢复仍保留其他故障，页面分别解释自报离线及自检异常。
- 发布工具原来默认读取旧 `out/gb28181/gateway`，且回滚会把“开机启用但当前停止”改成禁用，也不能正确恢复“禁用但手工运行”和仅本次开机启用。三组旧脚本失败已复现；新增只读候选/媒体/许可证/ARM64校验，允许显式绑定已验收网关，默认构建必须有完整四组件校验清单，安装复制后再次核对。更新保留服务状态，安装/回滚互斥，附运行许可证清单；工具回归使用隔离环境，实际发布另列。
- 新增通用控制台更新器只消费现有已编译前后端；校验源码与产物，保留有界旧页面资源和恢复目录，仅重启后端。它不再通过ONVIF整包部署间接更新其他微服务。真实目录交换配合模拟服务命令覆盖成功、健康失败回滚、并发冲突和中断恢复；R12c已实际独立发布，未执行生产回滚演练。
- 向导中的浏览器原生放弃确认改为统一站内弹窗，保留草稿、右上角关闭、Esc、键盘焦点约束、忙时防止重复操作。浏览器验收发现放弃设备草稿后触发按钮被移除导致焦点落到背景；新增复现测试并修正返回仍打开的父向导。取消和关闭均不隐式保存。

规范来源、官方正文定位与未实现的条款见 `STANDARD-2022-AUDIT-20261025.md` 和 `coverage-2022.json`。MP4 存储及 Note 全信令摘要的差异仍存在；不把受限实时接入写成全标准符合。
