# AINVR 国标摄像头接入

## 架构与使用

摄像头/NVR → SIP 网关 + 独立 ZLMediaKit RTP/PS 接收 → FFmpeg 音视频桥接 → **现有 SRS**。
不替换 SRS。视频只复制，不解码或转码；AAC 复制，G.711 A-law/μ-law 转 AAC。
不支持的音频显式显示不可用，视频继续。原始输入不叠加 AI 内容。

1. **系统配置 → 国标接入配置**：填写平台 SIP 编号、域、摄像头能访问的信令和媒体 IP、端口范围、容量；确认网关应用状态。
2. **接入管理 → 新建通道 → GB/T 28181 摄像头 / NVR → 接入参数**：预先添加设备编号和独立注册密码；在摄像头上填写相同平台参数。
3. 设备注册后获取目录，搜索并单个或批量选择接入通道。目录状态与真实收流状态分别显示。
4. 新输入沿用监看、录像及 AI 输入选择。每个接入映射只有一套媒体会话；关闭浏览器不停止收流。
5. 停用保留输入 UUID、录像和 AI 关联。目录暂时缺项不自动删除历史。已有映射的设备不能直接删除，可停用。

输入内部使用 RTMP，以稳定的 `gb_<binding UUID>` 发布到 SRS；国标设备身份、目录身份与 AINVR UUID 分开保存。
普通通道编辑可以改名称，不能改国标绑定的发布身份。若输入被删除/导入覆盖/停用，后台停用映射并记录审计，不擅自恢复客户删除的通道。

## 配置与边界

- 默认平台关闭，媒体并发上限 4。发现目录的数量不等于可同时收流数量。
- 管理接口 `127.0.0.1:8096`，ZLM HTTP/RTSP 仅回环 `8097/8556`。
- SIP 默认 `5060` UDP/TCP；媒体默认 `30000–30100`。启用前核对端口冲突、路由和摄像头可达地址。
- 支持局域网和可路由专网；不承诺任意 NAT 穿透。
- TCP 被动：摄像头主动连接网关；TCP 主动：网关连接摄像头。页面明确标出角色。
- SDP 接受单路 PS/90000、相同 SSRC、注册源 IP；NVR 独立媒体地址可在设备表单显式配置（最多 8 个单播 IPv4），未配置地址、回环、链路本地和组播地址不被额外信任。真实 NVR 兼容仍待验收。
- 外置网关管理使用受信HTTPS；媒体桥接和SRS查询保持回环，通过部署层受限加密转发连接AINVR。两版外置模拟拓扑及断开恢复已验证，物理外置主机和厂商设备仍待验收。配置步骤及安全边界见 [EXTERNAL-GATEWAY.md](EXTERNAL-GATEWAY.md)。
- 配置更新会重建国标会话；其他输入、SRS、AI、录像服务不由网关重启。
- 支持方向、停止、变焦及预置点控制，能力与布防保护见 [PTZ 合同](../docs/PTZ-CONTROL-CONTRACT.md)。不包含对讲、摄像头历史查询、上级级联、GB35114 安全认证。

## 已实现

- sipgo SIP 解析/事务/UDP/TCP；预配置注册、摘要鉴权、刷新/注销、心跳离线、nonce 期限和重放拒绝。
- 2016/2022 版本配置与标识；自动模式无证据时 2016 兼容并标版本未确认。
- 有界 XML、目录分批、幂等与查询代次；DeviceInfo/DeviceStatus 查询应答、重新注册重新获取目录。
- INVITE/SDP、ACK/BYE、取消与迟到成功应答清理；独立端口/SSRC 租约、有限并发、退避恢复。
- 与参数库集成，增量迁移 012，加密凭据，配置版本冲突检查，稳定映射与审计。
- 系统配置、设备目录、批量接入、自动状态刷新、服务列表和日志入口。
- 独立 FFmpeg 音频桥接构建；ZLM HTTP-FLV → SRS 保留 B 帧的 DTS/PTS，避免 RTSP 桥接丢失时间戳。

## 构建、测试与部署

锁定信息：`dependencies.lock.json`、`go.sum`。WVP 子模块只读参考，不进入运行时。

```sh
sh deploy-package/gb28181/build.sh
cd gb28181-service
GOTELEMETRY=off GOPROXY=off GOMAXPROCS=2 ../out/gb28181/go/bin/go test -race -p 2 -timeout 45s ./...
```

`test/gb28181/matrix.py` 串行执行 96 个组合，每例有限时、独立端口和独立 SRS；不会修改现有 SRS。
`test/gb28181/pipeline_probe.py` 的成功只证明对应组合的实际媒体链路，不替代完整矩阵或长期验收。
真实参数库测试：设置 `AINVR_GB_TEST_PG=1`，测试专用回环端口 25439，每次创建并清理自己的随机 schema。
**不要把该测试配置指向生产参数库。**

新增网关和媒体策略须先完成媒体/长测验收；兼容性界面修复可独立更新控制台。只读预检不操作服务；不能把“预检通过”当成媒体验收通过。

```sh
python3 deploy-package/deploy_ptz_release.py --check out/<verified-ptz-release>
sh deploy-package/gb28181/install.sh --check \
  --gateway "$PWD/out/gb28181/<verified-gateway>" \
  --gateway-sha256 <accepted-sha256>

# 各候选完成对应验收后，分别执行：
python3 deploy-package/deploy_ptz_release.py --apply out/<verified-ptz-release>
sh deploy-package/gb28181/install.sh \
  --gateway "$PWD/out/gb28181/<verified-gateway>" \
  --gateway-sha256 <accepted-sha256>

# 失败保留恢复目录；按相反顺序恢复组件和控制台：
sh deploy-package/gb28181/rollback.sh /mnt/ainvr-ssd/ainvr-rollback/gb28181/<timestamp>
python3 deploy-package/deploy_ptz_release.py --rollback /mnt/ainvr-ssd/ainvr-rollback/backend/<timestamp>
```

默认构建安装仍可不传网关参数，但必须有 `build.sh` 完整写出的四组件 `artifacts.sha256`；缺失、过期、媒体二进制/ARM64架构/依赖许可证不符均在改服务前拒绝。显式网关须在本仓库 `out/`，并匹配实际验收哈希；不再静默选取旧 `out/gb28181/gateway`。媒体依赖仍匹配 `dependencies.lock.json`，安装后的复制内容再次校验；重新构建导致固定媒体哈希变化时必须重新核对并验收，不直接绕过锁定。

组件安装工具不改变平台业务开关，不删除参数库或历史，不重启 SRS/AI/录像。更新已有国标服务保留原运行和开机状态；安装与回滚互斥，自动失败回滚继承安装锁。旧备份若未记录开机状态只能保留原兼容恢复方式，不能追溯出当时的精确状态。运行目录附依赖许可证、库存和已安装校验清单。

联合发布更新控制台、AI、告警及两套协议服务，保留参数与历史数据，不重启 SRS、录像和其他被监视的媒体服务。只有相应验收通过的联合候选才能发布。所有回滚包位于已挂载 SSD 的 `ainvr-rollback/<service>/`，每服务最多三份。已被清理的历史目录不是恢复点；以当前完整的 `deployment.json` 和预检为准。

构建产物、密钥、媒体样本、长测试日志不提交。分发时附上依赖许可证、对应源码和构建选项，尤其 FFmpeg LGPL 源码提供义务；不能只附二进制哈希。


## 历史修正记录：2026-10-25 恢复与部署

- 同一设备从同一 IP 换端口/信令传输必须重新鉴权；成功后递增会话代次、重取目录，旧端口消息失效。不同 IP 在原注册有效时仍拒绝冲突注册；设备 IP 也变更时须等待旧注册离线，不能保证此情形 60 秒内恢复。
- 迁移 013 增加设备级媒体地址名单，默认空，保留既有映射。先升级兼容网关，再升级后端和前端。
- 当前网页入口 8088；127.0.0.1:8080 是 SRS 内部媒体 HTTP，不能作为控制台端口替换。可另行给 Nginx 增加 80 入口并保留 8088；本轮未变更网络入口。
- 当时的长测运行旧网关，不用于证明本轮 R12 通过；当前结果以本页发布状态和发布审查报告为准。

## 2026-10-25 自动兼容与提交补充

- 每个设备可选自动、2016、2022；默认自动。明确的 2.0/3.0 声明分别对应 2016/2022，未声明采用 2016 兼容配置并保留“版本未确认”。未知声明不猜测；手动 2022 遇到明确 2016 声明仍报告不兼容。
- 状态分别返回所用 profile 和设备声明 peer；confirmed 仅表示收到已识别的版本声明，不代表完整标准认证或真机验收。页面分开显示两者。
- REGISTER 遵循 RFC 3261 §10.3：Contact expires 优先于 Expires，包括注销值 0；无有效期时采用默认值；非法值拒绝，短有效期仍返回 423。
- 自动目录/设备信息/状态查询最多并发 4 台，每台仅一个自动查询周期；按最早尝试优先，失败结束本轮并等待冷却，不让一台慢设备阻塞全部设备。全局事务上限仍保留。
- 本次 Go race 测试、go vet、前端国标向导 10 项测试及生产构建通过。正式 2022 全文核对缺口、真机兼容及本次二进制长时媒体运行不在这些测试的证明范围内。

## 2026-10-27 协议与故障恢复修正

- 2016/2022 注册正有效期不足 3600 秒返回 423 / Min-Expires:3600；未提供有效期默认 86400 秒。0 仍为鉴权后的注销，Contact expires 优先。
- TCP 信令解析容量与受限 XML 容量对齐，独立 TCP 报文覆盖大于 64 KiB 的目录，不再在 XML 校验前静默断开。
- 媒体发布前及运行中核对 ZLM 实际 RTP 对端地址；不以 SDP 自报地址代替实际来源证明。
- 网关重启盘点现存 RTP 端口和 SSRC，只回收本平台明确命名的孤儿接收器；未知接收器不删除。失败绑定轮换端口，已关闭 SSRC 短时隔离，编号耗尽有界拒绝。
- 官方 2022 附录 D 要求首次 TCP 连接失败后至少重连三次；实现为首次加三次、间隔至少一秒。ZLM 五秒建连结果使用六秒管理请求期限，其他媒体 API 保持三秒。
- 通道详情补充国标媒体与音频状态，不支持的视频编码立即给出明确原因，不再等待后误报缺少媒体。
- 音频与时间戳验收新增内容级判据：关闭 ZLM 自动补静音，保留同一 PS 源的原始音视频时间戳。既有配置通过安装器按项迁移，保留密钥、地址和其他选项；不能仅替换 Go 二进制而遗漏媒体策略。
- 测试 PS 生成器按完整 PMT 预声明音轨，避免初始 PSM 只有视频而使接收器过早结束音轨发现。新生成器和样本使用独立文件名，不替换正在执行的旧长测输入。
