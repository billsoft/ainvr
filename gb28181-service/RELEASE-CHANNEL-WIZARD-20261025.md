# 国标通道向导产品化收尾（2026-10-25）

## 操作流程

所有来源从接入管理的“新建通道”进入，统一三步：基本信息、接入参数、播放设置。
国标设备注册身份在接入参数内登记；注册信息必须先落库，设备才可注册并返回目录。表单明确提示该操作立即保存且 NVR 多通道共用身份。视频通道的名称、备注、目录映射、传输方式、启停和播放协议在最后一步一次提交。
NVR 支持多选目录，批量名称预览，整批事务保存。容量不足或冲突时整批回滚。
平台 SIP 标识、信令地址、媒体端口、服务密钥及容量仅在系统配置的国标接入分类管理。

## 修复与兼容

- 不再显示独立国标接入面板，避免与普通通道入口割裂。
- 通过 channel_config / applied_config 持久化期望配置，后台重试应用；网关未配置也可生成稳定输入通道。
- 保存名称、备注和播放设置，不再被目录默认值覆盖或由独立绑定按钮丢弃。
- 编辑前读取最新映射；映射元数据与版本号使用同一数据库查询快照。状态轮询不推进草稿版本，拒绝过期覆盖。
- 登记设备成功属于本次编辑自己的版本推进，随后视频保存可继续；其他操作产生的冲突需关闭后重新编辑。
- 国标运行时失败不阻止普通通道编辑；已有国标映射读取失败时拒绝使用旧快照编辑。
- 取消、关闭和 Escape 保护草稿，关闭后焦点返回原按钮。
- 未调整现有 RTMP/RTSP 通道、流媒体、录像、AI 或热区数据；输入仍经独立网关桥接。
