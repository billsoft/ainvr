# 生产参考审核

单并发、按告警时间从新到旧读取未审核告警；截图先检查绑定和原文件完整性。
历史截图经 JPU 解码、GLES 去对齐填充和等比例适配、JPU 编码后调用生产大模型。
分数写入 review.reference，不修改 handling 或原 review.state。人工抢先处理会使写入栅栏失效。
崩溃任务在 180 秒租期后接续，临时故障最多尝试三次；缺图和身份不符不重试。
参考输入单独保留在 SSD，最多 128 MiB／7 天，定期清理；核心告警、录像不等待此任务。

部署：先执行 reference-review.test.mjs 的真实隔离 Mongo 测试、前端告警测试和编译，
再执行 install.sh。安装路径固定为本次发布目录；重复发布须更改版本名，不覆盖现有目录。
回滚：执行 rollback.sh，保留已保存分数，不改变业务审核结果。前端回滚可使用
out/gb28181/rollback-submit-20261025/frontend-dist。

这是持续启用的生产参考分析，UI 显示“AI 参考分数 · 待验证”。正式自动审核仍由
ReviewWorker 和签名资格校验管理，不能把本服务的分数称为已审核或验证准确率。
