# AINVR Alarm Service

独立告警服务，消费 AI 服务的真实检测、跟踪及原帧身份；不执行模型、不创建 SRS 通道。

## 当前接口与数据职责

- Web 后端通过认证接口保存触发器定义、来源警戒区和选用关系；参数库为配置权威。一次布防保存原子更新区域和选用，使用版本冲突检查与幂等操作号。
- 触发器定义不选择通道，每项定义只有一种行为：出现、接近、碰撞侵入、穿过。在实时画面将定义选用到整幅画面或指定警戒区，执行规则按选用编号生成。
- 告警服务按每帧观测驱动判定。普通 2D 位置使用框底边中点；接近距离按画面宽度百分比换算；穿过需有真实外→内→外证据，预测框不证明越界。
- 同目标活动合并告警并保留最高级别；行为事实独立持久化供统计。人工确认不改变统计事实；仅统计触发器不产生告警。
- VLM、外部通知本期只预留接口。
