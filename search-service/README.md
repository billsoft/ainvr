# AINVR search-service

默认包是 SigLIP2 Base 256（768 维，`siglip2-base-full-int8`）。Qwen3-VL-Embedding-2B（全 BPU，2048 维，`qwen3vl-embedding-2b-o2`）
是可选包，2026-11-02 曾上线后按用户决定换回，说明见 `../docs/SEARCH-QWEN3VL-EMBEDDING.md`；换包都要清空重积累（`deploy-package/search_fresh_model_cutover.mjs`）。
2026-10-29：基础采样、检索与异步参考复核已部署开发测试板（当时默认包 `siglip2-base-full-int8`）。当前修复与发布证据见
`../docs/AI-SEARCH-RELEASE-20261029.md`；接口联调不代表现场准确率验收。

## 架构与运行边界

- 复用现有C++17原生服务、配置中心及任务队列。PG保存参数、授权、任务和审计；
  现有Mongo历史库单文档保存JPEG、向量及元数据，SSD保存可重建索引。
  不引入另一套数据库或任务系统，不把图片拆成独立文件管理。
- 程序、模型和依赖位于系统盘。缺SSD/历史库时报告不可用，不回退eMMC存历史。
- 生产推理只用已校验HBM/BPU；图像使用GLES/JPU及专用媒体硬件，不启用CPU兜底。
  模型包、分词器和sidecar不随程序发布复制，也不从编译目录自动加载。
- Qwen3-VL-Embedding 的权重只在 ai-service 里加载一份（图片与查询共用文本解码器）；本服务的文本编码器
  只是它的本地套接字客户端（`remote_text_encoder.*`），不加载模型。
- 每个历史命名空间只有一个拥有写权的进程。HTTP代次先停止接收并排空处理器，
  再停止后台所有者；相同完整模型pin可跨配置代次复用文本塔，权限与HTTP对象不复用。
  模型或存储变化仍重建相应资源；不是所有配置变化都能无中断热更新。

## 视图布局（与检测框无关）

SigLIP2 包的一个场景样本带 **4 个视图向量**（整帧 + 沿长边展开的 3 个短边方块：横图左/中/右，竖图上/中/下，方块边长 = 短边），
按视图顺序拼成一条 4×768 = 3072 个浮点数的记录，每个视图块各自 L2 归一化；每个视图都压成 256×256，不补边
（保长宽比的补边在 2026-11-04 的 A/B 中显著更差）。布局和视图规划在 `../shared/cpp/search_views.hpp`，布局名写进包的输入规格，
所以向量空间版本（model_version）随布局变化，旧布局的数据不会混入。

- 查询向量是一个视图块（768 维）；一条记录的得分是它各视图得分的最大值，结果带 `matched_view`（0 = 整帧，1..3 = 方块）和 `view_layout`。
- 检测框、检测类别、轨迹都不参与：该空间里目标（框）样本会被明确拒绝。
- 容量按浮点数计：内存里的精确检索窗口上限 128M 浮点，4 个视图时约 41,600 个样本（所有通道合计）。
- 迁移（重编码已存样本）不支持多视图包，返回 `migration_multiview_unsupported`。

## 采样与回执

真实检测和原帧身份决定证据；预测框不产生图片事实。沿用会话、源PTS、帧号、
原图/观测图尺寸及原始输入、AI输出、录像通道身份。未经验证的ERP拒绝新采样，
历史仍可查询。首版场景是整帧，有限分块需要效果与成本对照后准入。

每条已确认轨迹最多8槽，ACK后更新首帧、像素支持较好的帧及变化槽；几何支持分
不是测得的清晰度。外观变化阈值仍为实验参数，不宣称已标定最优。
搜索有独立有界执行器及元数据通道，不占识别归档池。硬件owner维持同线程加载、
执行和释放；借用帧必须等SDK任务真正结束，超时不能提前释放DMA。

写入结果未知只查原请求回执，不重编码、不重发、不把not_found当作拒绝。
Unknown超过本地保留期限可退休旧身份并记录缺口：场景只允许之后的新帧，
对象必须等跟踪器退休该编号后才能重新建立槽位；迟到ACK不能污染新代。

覆盖账本和索引完整性分别计算。未记账样本不能变成sampled；元数据积压只降低
覆盖可信度，不反向永久阻止采样。连续性需要同生命周期、帧号和时间证据；真实
断流不填平。相同最终区间幂等，冲突终态保守显示gap。

## 查询与界面

精确余弦检索先按已授权通道和半开时间范围过滤，再按来源/会话/轨迹聚合；
不同目标不因相似或邻近而合并。RAM最多128M floats（2048维时62,500条），不能承诺有限工作集覆盖
全部历史。范围恢复有界，耗尽证明绑定单写入者代次；持久不确定写入不能被重启抹去。
批量核对可见样本及指纹，Mongo I/O不占候选处理的投影锁。

查询快照最多60个稳定引用槽位，不复制图片或向量。过期、删除、撤权和槽位替换
均重新验证；旧得分不搭配新图片。逐帧目标框按实际展示JPEG坐标换算，未知旧坐标
不猜框；场景不冒充精确目标。关键时刻是稀疏采样，连续过程以录像为准。

界面渐进更新，不自动重排正在查看的候选。显式重排仅针对已加载结果，后续分页
追加；入口范围可继承/清除。覆盖按来源和对象/场景显示，覆盖服务资源错误降为
unknown而保留候选，鉴权错误仍拒绝。类别硬筛选尚未准入，默认保留开放场景召回。

复核复用LLM独立调用身份和固定版本模板；告警优先、搜索有防饿死。profile临时
不可用不领取/终结任务；推理后等待profile恢复时保留唯一结果，不重新推理。
活跃任务按用户公平领取，有工作立即继续、空闲才等待。输出仍是AI参考，不当概率。

## 容量与迁移

额度按完整BSON计算，包含JPEG、向量及元数据；Mongo索引/日志另留余量。
保留天数是上限，不是默认1GiB能装满30天的承诺。满额拒绝不悄悄覆盖证据；
管理员配置页显示实际条数、总字节、平均每条体积及覆盖额度。按真实机位负载规划。

大历史模型迁移默认关闭。只有`AINVR_SEARCH_MODEL_MIGRATIONS_ENABLED=1`及双方
能力具备才允许新计划，旧任务仍可恢复。旧单任务新增入口已关闭，历史读取与取消
保留。M4的settled-H0/增量证明及清单发布仍未通过，不得当作基本检索的发布结论。
编码/只读暂时故障有无进展预算；冻结写请求和未知checkpoint仍按幂等协议对账。
